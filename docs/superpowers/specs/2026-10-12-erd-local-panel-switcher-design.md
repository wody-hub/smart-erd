# ERD 로컬 좌측 패널 전환 탭 설계

- Date: 2026-10-12
- Scope: `/erd-local` 화면에서 테이블 목록과 코드 에디터를 좌측 패널 안에서 전환
- Non-goals: 일반 다이어그램 화면의 전환 UI 변경, 코드 편집기 동작 변경, 저장 방식 변경

## Current Behavior

`ErdLocalPage`는 좌측 224px 패널에 테이블 목록 또는 `DdlCodeEditorPanel` 중 하나를 표시한다. 전환 버튼은 캔버스 상단 툴바에 있어 패널 안에서 기능을 찾기 어렵고, 코드 화면에서는 테이블 목록으로 돌아가는 전환이 같은 위치에 표시된다. 코드 편집기는 SQL DDL/논리명 DSL 입력을 ERD에 자동 반영하고, 로컬 ERD 저장 흐름을 통해 변경을 보존한다.

## Design

좌측 패널 상단에 항상 노출되는 두 개의 탭 `테이블`과 `코드`를 배치한다. 선택된 탭이 현재 패널 내용을 결정한다.

- `테이블`: 기존 `DiagramSidebar`를 표시한다. 테이블 추가와 그룹 관리 동작은 그대로 유지한다.
- `코드`: 기존 `DdlCodeEditorPanel`을 표시한다. SQL DDL/논리명 DSL 하위 탭, 코드 자동 반영, 로컬 저장은 유지한다.
- 전환 탭은 두 패널 상태에서 계속 표시해 코드 화면에서도 테이블 목록으로 쉽게 돌아가게 한다.
- `/erd-local` 캔버스 툴바의 코드 에디터 전환 버튼은 제거한다. 일반 다이어그램 화면의 기존 툴바 전환 동작은 변경하지 않는다.

## Interaction and Accessibility

- 전환 탭은 텍스트를 포함한 segmented tab UI로 렌더링하고, 아이콘만으로 의미를 전달하지 않는다.
- 기존 `Tabs`, `TabsList`, `TabsTrigger` 컴포넌트를 사용해 `role="tablist"`, 선택 상태, 키보드 탐색을 제공한다.
- 키보드 포커스 표시와 기존 프로젝트의 탭 색상 토큰 및 간격을 따른다.
- 패널 너비는 현재 224px를 유지한다. 코드 편집기의 SQL DDL/논리명 DSL 선택은 하위 수준의 별도 탭으로 둔다.

## Components and State

`ErdLocalPage`가 `leftPanel` 상태를 소유하며, 좌측 래퍼의 상단에서 모드 전환 탭을 렌더링한다. 선택 상태와 클릭 핸들러는 기존 `leftPanel` 및 `handleToggleCodeEditor` 흐름을 대체해 명시적 패널 선택을 처리한다. 공용 `CanvasToolbar` API는 다른 화면에서 계속 사용하므로 변경하지 않는다. `/erd-local`에서는 `ERDCanvas`에 코드 전환 callback을 전달하지 않아 중복 진입점을 없앤다.

## Data Flow and Persistence

패널 전환은 표시 상태만 변경하며 캔버스 데이터를 변경하지 않는다. 코드 입력 → ERD 반영 → 기존 로컬 자동 저장의 흐름과 파일 저장/불러오기 동작은 그대로 유지한다. 패널 콘텐츠의 마운트/언마운트 동작은 현재 조건부 렌더링과 동일하게 둔다.

## Validation

- 정적 확인: 좌측 전환 탭의 라벨, 선택 상태, 접근성 속성, 폭 224px 내 레이아웃 확인
- 기능 확인: 테이블 ↔ 코드 반복 전환, 코드에서 SQL DDL/논리명 DSL 입력 후 캔버스 반영과 자동 저장 확인
- 회귀 확인: 좌측 테이블 추가/목록/그룹 UI와 캔버스 툴바 기능, 일반 다이어그램의 코드 전환 확인
- 자동 검사: 관련 단위 테스트, TypeScript 빌드 및 포맷 검사
