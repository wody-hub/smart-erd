# 테이블 그룹 — 구현 설계서

> **상태**: 구현 대기
> **작성일**: 2026-02-25
> **기반 문서**: `plan/테이블-그룹-논리적묶음-기획서.md` (v2)

## 1. 설계 결정 요약

| 결정 항목 | 선택 | 근거 |
|-----------|------|------|
| 시각적 그룹 처리 | 완전 제거 (방안 A) | 사용자가 시각적 박스 불필요 명시 |
| `tableIds` Yjs 타입 | `Y.Array<string>` | 순서 보존, 그룹당 테이블 수 수십 개 이내로 O(n) 스캔 무해 |
| `tableIds` 중복 방지 | 읽기 시 deduplicate | CRDT 동시 추가 시 중복 가능 → `yGroupsMapToTableGroups()`에서 `Set` 기반 제거 |
| `activeGroupId` 배치 | `DiagramPage` 내 `useState` | 로컬 UI 상태, prop drilling 범위 제한적 (Sidebar + ERDCanvas) |
| 댕글링 참조 방어 | `useEffect` + toast | 원격 사용자가 그룹 삭제 시 `activeGroupId` 자동 리셋 |
| 그룹 뷰 전환 시 뷰 맞춤 | `fitView` 호출 | `activeGroupId` 변경 시 `requestAnimationFrame` → `reactFlowInstance.fitView()` |
| `activeGroupTableIds` 안정성 | `join(',')` 기반 안정 키 | Yjs observer가 매번 새 배열 참조 생성, `Object.is` 비교 회피 위해 문자열 키 사용 |
| `useCallback` 사용 여부 | 기존 파일 패턴 유지 | 신규 핸들러(`handleViewGroup`, `handleBackToAll`)는 일반 함수, 기존 핸들러(`handleToggleCodeEditor`)는 useCallback 유지하여 파일 내 일관성 보존 |
| 백엔드 변경 | 없음 | groups가 Diagram content JSON에 포함, 스키마 변경 불필요 |
| `buildRevisionHash`와 groups | groups 해시 제외 | DSL/DDL 코드에 그룹 개념 미포함 → tableIds 변경이 코드 동기화를 트리거할 이유 없음 |
| `fkMode` 취소 위치 | ERDCanvas `handleNodeClick` 가드 | `fkMode` 분기에 `effectiveCanEdit` 조건을 추가하여 그룹 뷰에서 FK 관계 추가를 차단. DiagramPage에서 별도 취소 불필요 |
| `SIDEBAR_ENTRY_SEPARATOR` 위치 | Sidebar.tsx 로컬 상수 | 단일 파일에서만 사용되므로 별도 파일 추출 불필요 |
| `updateGroupColor` UI | v1 미노출 | 액션만 정의, UI 진입점은 추후 구현 — 색상 변경은 기존 `updateGroupMeta` 활용 가능 |
| 로컬 삭제 toast 방지 | `onDelete` 래핑 | `activeGroupId === group.id`일 때 `onBackToAll` 선호출 → CRDT observer 댕글링 감지 toast 방지 |
| `onToggleCodeEditor` 차단 위치 | DiagramPage 단일 제어 | DiagramPage가 prop으로 `undefined` 전달, ERDCanvas 내부 중복 가드 불필요 |
| 그룹 테이블 추가 시 dangling 방어 | `handleConfirm` 내 필터링 | 다이얼로그 열린 동안 원격 삭제된 노드를 `currentNodeIds`로 필터링하여 제외 |
| 캔버스 상단 배너 | v1 사이드바 배너만 | 기획서 4.2에 캔버스 내부 배너 명시, 그러나 사이드바 배너로 충분한 상태 인지 제공 — 추후 캔버스 배너 추가 가능 |
| Ctrl+S 그룹 뷰 | 유지 | 기획서 "비활성" 명시이나, 저장은 전체 스냅샷이므로 그룹 뷰와 무관하게 동작해야 함 |
| 그룹 색상 도트 | v1 미노출 | 기획서 4.4 명시이나, `updateGroupColor` UI와 함께 v2에서 구현 — 마이그레이션 시 색상 보존만 수행 |
| `handleNodeClick` 그룹 뷰 차단 | `effectiveCanEdit` 적용 | fkMode 분기 포함 모든 편집 경로에 `effectiveCanEdit` 가드 적용. useHotkeys DELETE, onEdgeContextMenu, onNodeDragStart/Stop도 동일 적용 |
| 그룹 테이블 추가/제거 원자성 | `updateGroupTables` 단일 트랜잭션 | `addTablesToGroup` + `removeTablesFromGroup` 별도 호출 시 observer 2회 트리거 + 중간 상태 노출 → 단일 Yjs 트랜잭션으로 원자적 처리 |
| 다이얼로그 원격 변경 방어 | 열림 시 스냅샷 저장 | `existingTableIds` 스냅샷으로 diff 기준 고정. 다이얼로그 열린 동안 원격 tableIds 변경으로 인한 의도하지 않은 제거 방지 |

#### 2.3.2 `yGroupsMapToNodes()` → `yGroupsMapToTableGroups()` 교체

**삭제:**
```typescript
export function yGroupsMapToNodes(groupsMap: Y.Map<Y.Map<unknown>>): Node<GroupNodeData>[] {
  // ... 전체 삭제
}
```

**추가:**
```typescript
/**
 * Y.Map으로 표현된 그룹들을 TableGroup 배열로 변환한다.
 *
 * @param groupsMap Y.Map<groupId, Y.Map>
 * @returns 논리적 그룹 배열
 */
export function yGroupsMapToTableGroups(groupsMap: Y.Map<Y.Map<unknown>>): TableGroup[] {
  const groups: TableGroup[] = [];

  groupsMap.forEach((groupYMap, groupId) => {
    const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
    // CRDT 동시 추가로 중복이 발생할 수 있으므로 읽기 시 deduplicate
    const seen = new Set<string>();
    const tableIds: string[] = [];
    if (tableIdsYArray) {
      tableIdsYArray.forEach((id) => {
        if (!seen.has(id)) {
          seen.add(id);
          tableIds.push(id);
        }
      });
    }

    groups.push({
      id: groupId,
      label: (groupYMap.get('label') as string) ?? 'Group',
      color: groupYMap.get('color') as TableHeaderColor | undefined,
      tableIds,
    });
  });

  return groups;
}
```

```typescript
/**
 * 논리적 그룹 데이터를 Y.Map으로 변환한다.
 *
 * @param label    그룹 이름
 * @param tableIds 소속 테이블 ID 배열
 * @param color    색상 (옵션)
 * @returns Y.Map 인스턴스
 */
export function createGroupYMap(
  label: string,
  tableIds: string[] = [],
  color?: TableHeaderColor,
): Y.Map<unknown> {
  const groupYMap = new Y.Map<unknown>();
  groupYMap.set('label', label);

  const tableIdsYArray = new Y.Array<string>();
  if (tableIds.length > 0) {
    tableIdsYArray.push(tableIds);
  }
  groupYMap.set('tableIds', tableIdsYArray);

  if (color && color !== 'default') {
    groupYMap.set('color', color);
  }
  return groupYMap;
}
```

#### 2.3.6 새 유틸 함수 추가

```typescript
/**
 * 그룹의 tableIds Y.Array에서 특정 테이블 ID를 제거한다.
 *
 * @param tableIdsYArray tableIds Y.Array
 * @param tableId        제거할 테이블 ID
 * @returns 제거 성공 여부
 */
export function removeTableIdFromYArray(
  tableIdsYArray: Y.Array<string>,
  tableId: string,
): boolean {
  let removed = false;
  // CRDT 동시 추가로 중복이 존재할 수 있으므로 모든 매치를 제거한다.
  for (let i = tableIdsYArray.length - 1; i >= 0; i--) {
    if (tableIdsYArray.get(i) === tableId) {
      tableIdsYArray.delete(i, 1);
      removed = true;
    }
  }
  return removed;
}
```

### 2.5 `client/src/stores/canvas/canvasGroupActions.ts` — 전체 재작성

```typescript
import * as Y from 'yjs';
import {
  createGroupYMap,
  getGroupsMap,
  removeTableIdFromYArray,
} from '@/collaboration/yjsBridge';
import type { TableHeaderColor } from '@/types/erd';
import type { CanvasGetState, CanvasState } from './canvasStoreTypes';

type CanvasGroupActionKeys =
  | 'addGroup'
  | 'deleteGroup'
  | 'renameGroup'
  | 'updateGroupColor'
  | 'addTableToGroup'
  | 'addTablesToGroup'
  | 'removeTableFromGroup'
  | 'removeTablesFromGroup'
  | 'updateGroupTables';

/**
 * 캔버스 논리적 그룹 액션 팩토리.
 *
 * @param get Zustand 상태 getter
 * @returns   논리적 그룹 CRUD + 테이블 멤버십 액션 맵
 */
export function createCanvasGroupActions(
  get: CanvasGetState,
): Pick<CanvasState, CanvasGroupActionKeys> {
  return {
    addGroup: (label) => {
      const { ydoc, groups } = get();
      if (!ydoc) {
        return;
      }
      const groupId = `group-${crypto.randomUUID()}`;
      const groupLabel = label ?? `Group ${groups.length + 1}`;
      ydoc.transact(() =>
        getGroupsMap(ydoc).set(groupId, createGroupYMap(groupLabel)),
      );
    },

    deleteGroup: (groupId) => {
      const { ydoc } = get();
      if (ydoc) {
        ydoc.transact(() => {
          getGroupsMap(ydoc).delete(groupId);
        });
      }
    },

    renameGroup: (groupId, newName) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (groupYMap) {
        ydoc.transact(() => {
          groupYMap.set('label', newName);
        });
      }
    },

    /** v1 미노출 — UI 진입점은 추후 구현 */
    updateGroupColor: (groupId, color) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      ydoc.transact(() => {
        if (color === 'default') {
          groupYMap.delete('color');
        } else {
          groupYMap.set('color', color);
        }
      });
    },

    addTableToGroup: (groupId, tableId) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
      if (!tableIdsYArray) {
        return;
      }
      // 트랜잭션 진입 전 중복 체크 (빈 트랜잭션 커밋 방지)
      // CRDT 동시 추가 시 중복이 생겨도 yGroupsMapToTableGroups()에서 읽기 시 deduplicate로 처리됨
      for (let i = 0; i < tableIdsYArray.length; i++) {
        if (tableIdsYArray.get(i) === tableId) {
          return;
        }
      }
      ydoc.transact(() => {
        tableIdsYArray.push([tableId]);
      });
    },

    addTablesToGroup: (groupId, tableIds) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
      if (!tableIdsYArray) {
        return;
      }
      ydoc.transact(() => {
        // 기존 ID 수집
        const existing = new Set<string>();
        tableIdsYArray.forEach((id) => existing.add(id));
        // 중복 제외 후 일괄 추가
        const newIds = tableIds.filter((id) => !existing.has(id));
        if (newIds.length > 0) {
          tableIdsYArray.push(newIds);
        }
      });
    },

    removeTableFromGroup: (groupId, tableId) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
      if (tableIdsYArray) {
        ydoc.transact(() => {
          removeTableIdFromYArray(tableIdsYArray, tableId);
        });
      }
    },

    removeTablesFromGroup: (groupId, tableIds) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
      if (tableIdsYArray) {
        ydoc.transact(() => {
          for (const tableId of tableIds) {
            removeTableIdFromYArray(tableIdsYArray, tableId);
          }
        });
      }
    },

    /**
     * 그룹의 테이블 목록을 단일 Yjs 트랜잭션으로 갱신한다.
     * 추가와 제거가 원자적으로 처리되어 중간 상태 노출과 observer 이중 트리거를 방지한다.
     *
     * @param groupId  대상 그룹 ID
     * @param toAdd    추가할 테이블 ID 배열
     * @param toRemove 제거할 테이블 ID 배열
     */
    updateGroupTables: (groupId, toAdd, toRemove) => {
      const { ydoc } = get();
      if (!ydoc) {
        return;
      }
      const groupYMap = getGroupsMap(ydoc).get(groupId);
      if (!groupYMap) {
        return;
      }
      const tableIdsYArray = groupYMap.get('tableIds') as Y.Array<string> | undefined;
      if (!tableIdsYArray) {
        return;
      }
      ydoc.transact(() => {
        // 제거 먼저 (역순 삭제로 인덱스 안전)
        for (const tableId of toRemove) {
          removeTableIdFromYArray(tableIdsYArray, tableId);
        }
        // 추가 (중복 제외)
        const existing = new Set<string>();
        tableIdsYArray.forEach((id) => existing.add(id));
        const newIds = toAdd.filter((id) => !existing.has(id));
        if (newIds.length > 0) {
          tableIdsYArray.push(newIds);
        }
      });
    },
  };
}
```

**전체 구현:**

```typescript
/**
 * 그룹에 테이블을 추가/제거하는 멀티셀렉트 다이얼로그.
 *
 * 전체 테이블 목록을 체크박스로 표시하며,
 * "확인" 시 변경분(추가/제거)을 스토어에 반영한다.
 *
 * @param props.open             다이얼로그 열림 상태
 * @param props.onOpenChange     다이얼로그 열림 상태 변경 핸들러
 * @param props.groupId          대상 그룹 ID
 * @param props.groupName        대상 그룹 이름
 * @param props.existingTableIds 현재 그룹에 속한 테이블 ID 목록
 */
export default function GroupTableSelectDialog({
  open,
  onOpenChange,
  groupId,
  groupName,
  existingTableIds,
}: GroupTableSelectDialogProps) {
  const { t } = useTranslation();
  const nodes = useCanvasStore((s) => s.nodes);
  const updateGroupTables = useCanvasStore((s) => s.updateGroupTables);

  /** 로컬 선택 상태 (체크된 테이블 ID Set) */
  const [selected, setSelected] = useState<Set<string>>(() => new Set(existingTableIds));
  /** 다이얼로그 열림 시점의 existingTableIds 스냅샷 (원격 변경과 무관한 안정적 diff 기준) */
  const [snapshotIds, setSnapshotIds] = useState<string[]>(existingTableIds);

  // 다이얼로그가 열릴 때(open: false→true)만 기존 선택 상태 + 스냅샷 초기화
  useEffect(() => {
    if (open) {
      setSelected(new Set(existingTableIds));
      setSnapshotIds(existingTableIds);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps -- open 전환 시에만 초기화. existingTableIds 변경(원격 Yjs 업데이트)으로 사용자 선택이 리셋되는 것을 방지.
  }, [open]);

  const handleToggle = (tableId: string) => {
    setSelected((prev) => {
      const next = new Set(prev);
      if (next.has(tableId)) {
        next.delete(tableId);
      } else {
        next.add(tableId);
      }
      return next;
    });
  };

  const handleConfirm = () => {
    // diff 기준: 열릴 때 저장한 스냅샷 (원격 변경으로 인한 의도하지 않은 제거 방지)
    const snapshotSet = new Set(snapshotIds);
    const currentNodeIds = new Set(nodes.map((n) => n.id));
    // 새로 추가된 테이블 (원격 삭제된 노드는 제외)
    const toAdd = [...selected].filter((id) => !snapshotSet.has(id) && currentNodeIds.has(id));
    // 사용자가 명시적으로 체크 해제한 테이블만 제거
    const toRemove = snapshotIds.filter((id) => !selected.has(id));

    if (toAdd.length > 0 || toRemove.length > 0) {
      updateGroupTables(groupId, toAdd, toRemove);
    }
    onOpenChange(false);
  };

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>{t('erd.group.selectTables')}</DialogTitle>
          <DialogDescription>
            {t('erd.group.selectTablesDesc', { name: groupName })}
          </DialogDescription>
        </DialogHeader>
        <div className="max-h-64 overflow-auto space-y-1">
          {nodes.length === 0 ? (
            <p className="text-sm text-muted-foreground py-4 text-center">
              {t('erd.sidebar.noTables')}
            </p>
          ) : (
            nodes.map((node) => (
              <label
                key={node.id}
                htmlFor={`group-table-${node.id}`}
                className="flex items-center gap-2 px-2 py-1.5 rounded hover:bg-accent cursor-pointer"
              >
                <Checkbox
                  id={`group-table-${node.id}`}
                  checked={selected.has(node.id)}
                  onCheckedChange={() => handleToggle(node.id)}
                />
                <span className="text-sm truncate">{node.data.label}</span>
              </label>
            ))
          )}
        </div>
        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)}>
            {t('common.button.cancel')}
          </Button>
          <Button onClick={handleConfirm}>
            {t('common.button.confirm')}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

### 2.18 `client/src/lib/code-sync-revision.ts`

리비전 해시 계산에서 groups 파라미터를 완전히 제거한다. DSL/DDL 코드에 그룹 개념이 포함되지 않으므로, 그룹 변경이 코드 동기화를 트리거할 이유가 없다.

#### 2.18.1 `buildRevisionHash` 시그니처 및 구현 변경

```typescript
// Before
/** nodes/edges/groupNodes 스냅샷으로 결정적 리비전 해시를 계산한다. */
export function buildRevisionHash(
  nodes: RevisionSnapshotNode[],
  edges: RevisionSnapshotEdge[],
  groupNodes: RevisionSnapshotNode[],
): string {
  const payload = {
    nodes: [...nodes].sort((a, b) => a.id.localeCompare(b.id)),
    edges: [...edges].sort((a, b) => a.id.localeCompare(b.id)),
    groups: [...groupNodes].sort((a, b) => a.id.localeCompare(b.id)),
  };
  return djb2(JSON.stringify(sortObjectKeys(payload)));
}

// After — groups 파라미터 제거 (DSL/DDL에 그룹 개념 미포함)
/** nodes/edges 스냅샷으로 결정적 리비전 해시를 계산한다. */
export function buildRevisionHash(
  nodes: RevisionSnapshotNode[],
  edges: RevisionSnapshotEdge[],
): string {
  const payload = {
    nodes: [...nodes].sort((a, b) => a.id.localeCompare(b.id)),
    edges: [...edges].sort((a, b) => a.id.localeCompare(b.id)),
  };
  return djb2(JSON.stringify(sortObjectKeys(payload)));
}
```

> **변경 이유:** 논리적 그룹은 DSL/DDL 코드에 표현되지 않는다. 그룹 변경(label, color, tableIds)이
> 리비전 해시를 변경하면 ERD→코드 역방향 동기화가 불필요하게 트리거되어 사용자 코드를 덮어쓸 수 있다.
> groups 직렬화(`yDocToJson`)에서는 여전히 그룹이 포함되어 저장/백업에는 반영된다.

## 4. 협업 시나리오

| 시나리오 | 동작 |
|----------|------|
| A가 그룹 생성 | Yjs 동기화 → B의 사이드바에 즉시 반영 |
| A가 그룹에 테이블 추가 | Yjs 동기화 → B의 사이드바 그룹 하위 목록 갱신 |
| A가 그룹 뷰 진입 | A의 `activeGroupId` = local state → B에게 전파되지 않음 |
| B가 테이블 편집 (A는 그룹 뷰) | B의 편집이 Yjs로 A에게 전파 → A의 필터링된 뷰에도 실시간 반영 |
| A가 그룹 뷰에서 편집 시도 | `effectiveCanEdit = false` → 모든 편집 기능 비활성 |
| B가 테이블 삭제 (A의 그룹에 속한 테이블) | 테이블 삭제 + 그룹 tableIds에서 자동 제거 → A의 뷰에서도 즉시 사라짐 |
| B가 그룹 삭제 (A가 해당 그룹 뷰 중) | Yjs 동기화 → A의 `groups` 갱신 → `useEffect`가 댕글링 감지 → `activeGroupId = null` + toast 알림 |

## 8. 테스트 시나리오

구현 후 수동 검증:

1. **그룹 CRUD**: 생성 → 이름 변경 → 색상 변경 → 삭제
2. **테이블 멤버십**: 그룹에 테이블 추가 → 제거 → 다시 추가
3. **그룹 뷰**: Eye 아이콘 클릭 → 필터링 확인 → readonly 확인 → 전체 보기 복귀
4. **엣지 필터링**: 양쪽 모두 그룹 소속 엣지만 표시 확인
5. **테이블 삭제**: 그룹에 속한 테이블 삭제 → 그룹에서 자동 제거 확인
6. **협업**: 두 브라우저에서 그룹 생성/수정 → 실시간 동기화 확인
7. **그룹 뷰 독립성**: A가 그룹 뷰 진입 → B는 전체 보기 유지 확인
8. **마이그레이션**: 기존 시각적 그룹이 있는 다이어그램 → 빈 논리적 그룹으로 변환 확인
9. **코드 에디터 차단**: 그룹 뷰에서 코드 에디터 토글 비활성 확인
10. **N:M 관계**: 같은 테이블을 2개 그룹에 추가 → 각 그룹 뷰에서 표시 확인
11. **댕글링 참조**: A가 그룹 뷰 중 → B가 해당 그룹 삭제 → A가 자동으로 전체 보기 복귀 + toast 알림 확인
12. **fitView**: 그룹 뷰 진입 시 필터링된 테이블에 맞춤 줌/패닝 확인
13. **CRDT 중복 방지**: 두 브라우저에서 동시에 같은 테이블을 같은 그룹에 추가 → 중복 없이 1개만 표시 확인
14. **코드 동기화**: 그룹 뷰 진입 → 코드 에디터 전환 불가 확인 + 전체 보기 복귀 후 코드 동기화 정상 동작 확인
