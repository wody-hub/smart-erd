# DR-03 대용량 임계치 기본값 확정

- 상태: 확정 (2026-02-26)
- 오너: SRE + FE (riskzero-platform-sre-team + riskzero-development-team)
- 적용 범위: Phase 1/2 코드 동기화 정책 기본값 (`syncPolicy`)

## 1. 입력 근거

- Phase 1 구현 기본값
  - 경고 임계치: 150
  - 자동 Apply 제한 임계치: 300
- 성능 측정(`npm run perf:erd:apply`, 2026-02-26)
  - S50 total p95: 약 10.191ms
  - S200 total p95: 약 26.404ms
  - S500 total p95: 약 67.867ms

참고: 위 값은 로컬 단일 사용자 벤치마크이며, 실제 편집 환경(렌더링/협업 부하)에서는 더 높게 관측될 수 있다.

## 2. 옵션 비교

### 옵션 A

- 경고 150 / 제한 300 유지
- 장점: 현재 UX와 일치, 기존 문서/코드 일관성 유지
- 단점: 일부 저사양 환경에서 제한 시점이 늦을 수 있음

### 옵션 B

- 경고 120 / 제한 250 하향
- 장점: 보수적으로 위험 차단 가능
- 단점: 정상 자동반영 사용자 경험 감소

## 3. 결정

옵션 A(경고 150 / 제한 300)로 확정한다.

- 경고 임계치(150): 수동 주의 환기 시작 구간
- 제한 임계치(300): 자동 Apply 차단 및 수동 확정 전환 구간
- 대형 구간에서 `layoutMode=full` 요청은 `incremental`로 강등

## 4. 운영 규칙

- 기본값은 코드 상수로 유지하고, 다이어그램 단위 localStorage override 허용
- 팀 공통 정책 서버 저장은 Phase 2 범위에서 제외
- 릴리즈 후 2주간 임계치 경계(149/150/299/300) 이벤트를 모니터링

## 5. 재검토 트리거

다음 중 1개라도 만족하면 DR-03 재검토:

- 300 미만에서 자동반영 실패/보류 비율이 비정상 증가
- 300 이상에서 수동 전환 UX 불만이 주당 3건 이상
- 500 테이블 실사용 데이터에서 프리즈 이슈 재현

## 6. 후속 액션

- Phase 2 베타 시작 전, 실사용 로그 기준으로 임계치 재검토 회의 1회 수행
- 필요 시 `경고/제한`을 독립 조정 가능한 파라미터로 분리 검토
