# 프론트엔드 설계 — 사전 일괄 엑셀 다운로드

## 1. UI 위치

**DictionaryWorkspace** 컴포넌트의 사전 세트 선택 영역 옆에 **"전체 엑셀 다운로드"** 버튼을 배치한다.

```text
┌──────────────────────────────────────────────────────────────────┐
│  [사전 세트 선택 ▼]  [+] [✏️] [⭐] [🗑️]   [📥 전체 엑셀 다운로드]  │
├──────────────────────────────────────────────────────────────────┤
│  [ 단어 ]  [ 용어 ]  [ 도메인 ]                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  (각 탭 내용 — 기존 개별 다운로드 버튼도 그대로 유지)       │  │
│  └────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

### 위치 선정 이유

- 사전 세트 레벨의 액션이므로 **탭 바깥**, 세트 선택 영역에 배치.
- 각 탭의 개별 다운로드 버튼은 기존 그대로 유지하여 단일 시트 다운로드도 가능.
- 모든 역할(ADMIN, MEMBER, VIEWER)에서 사용 가능 (읽기 전용 액션).

## 2. API 함수

### `dictionarySetApi.ts` — 함수 추가

```typescript
/**
 * 사전 세트의 단어·용어·도메인을 하나의 엑셀 파일로 다운로드한다.
 *
 * @param teamId 팀 ID
 * @param setId  사전 세트 ID
 */
export async function downloadAllDictionary(
  teamId: string,
  setId: string,
): Promise<void> {
  const res = await axiosInstance.get(
    `/teams/${teamId}/dictionary-sets/${setId}/download/excel`,
    { responseType: 'blob' },
  );
  downloadBlob(res, 'dictionary-all.xlsx');
}
```

> 기존 패턴(`downloadDomainDictionary` 등)과 완전히 동일한 구조.

## 3. DictionaryWorkspace 변경

### 임포트 추가

```typescript
import { downloadAllDictionary } from '@/api/dictionarySetApi';
```

### 뮤테이션 추가

```typescript
/** 전체 사전 일괄 엑셀 다운로드 뮤테이션 */
const downloadAllMutation = useMutation({
  mutationFn: () => downloadAllDictionary(teamId, selectedSetId),
  onSuccess: () => toast.success(t('dictionary.export.allDownloaded')),
  onError: (err) =>
    toast.error(getErrorMessage(err, t('dictionary.export.allFailed'))),
});
```

### JSX — 버튼 추가

```tsx
<Button
  variant="outline"
  onClick={() => downloadAllMutation.mutate()}
  disabled={downloadAllMutation.isPending || !selectedSetId}
>
  <Download className="h-4 w-4 mr-2" />
  {downloadAllMutation.isPending
    ? t('dictionary.export.allExporting')
    : t('dictionary.export.allButton')}
</Button>
```

### 배치 위치

사전 세트 관리 버튼들(`+`, `✏️`, `⭐`, `🗑️`) 오른쪽, 또는 `canEdit` 블록 바깥에 별도 배치.
다운로드는 읽기 전용 액션이므로 `canEdit` 조건과 무관하게 항상 표시한다.

## 6. UX 고려사항

### 로딩 상태
- 버튼 텍스트가 "전체 내려받는 중..."으로 변경되고, `disabled` 처리.
- 3개 시트 데이터를 조회하므로 개별 다운로드보다 약간 느릴 수 있으나, 동일 API 1회 호출이므로 사용자 체감 차이는 미미.

### 사전 세트 미선택 시
- `selectedSetId`가 비어있으면 버튼 비활성화.

### 빈 데이터
- 데이터가 없는 시트도 헤더만 있는 빈 시트로 포함된다 (서버 측 처리).
- 프론트엔드에서 별도 처리 불필요.

### 권한
- 모든 역할(ADMIN, MEMBER, VIEWER)에서 사용 가능.
- `canEdit` 분기 밖에 배치.
