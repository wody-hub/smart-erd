# 구현 순서

## Phase 1: 백엔드 (선행)

### Step 1. `DictionaryWorkbookExportSupport` 리팩토링

1. 헤더/컬럼 상수를 package-private static final로 이동
2. `createTemplate()` 오버로드 추가 (기존 워크북 전달 버전)
3. 기존 시그니처는 내부에서 오버로드 호출로 위임 (하위 호환)

**영향 범위:** `DomainDictionaryExportService`, `TermDictionaryExportService`, `WordDictionaryExportService` — 상수 참조 변경 (동작 변경 없음)

### Step 2. `DictionarySetExportService` 신규 생성

1. `generateAllDictionary(loginId, teamId, setId)` 메서드 구현
2. 하나의 `XSSFWorkbook`에 3개 시트(단어 → 용어 → 도메인) 추가
3. 각 시트의 데이터 행 작성

### Step 3. `DictionarySetController` 엔드포인트 추가

1. `GET /{setId}/download/excel` 엔드포인트 추가
2. Swagger 어노테이션
3. `ExcelUtils.download()` 호출

### Step 4. 백엔드 검증

1. `./gradlew compileJava` — 컴파일 확인
2. 수동 테스트 또는 통합 테스트

---

## Phase 2: 프론트엔드

### Step 5. API 함수 추가

1. `dictionarySetApi.ts`에 `downloadAllDictionary()` 추가

### Step 6. `DictionaryWorkspace` 수정

1. 전체 다운로드 버튼 + 뮤테이션 추가
2. 로딩/비활성 상태 처리

### Step 7. i18n 키 추가

1. `ko/translation.json` — `dictionary.export.all*` 키 4개
2. `en/translation.json` — 동일 구조

### Step 8. 프론트엔드 검증

1. `npm run build` — 타입/빌드 확인
2. `npm run lint` — ESLint 확인
