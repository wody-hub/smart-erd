## 목적

현재 사전 페이지에서 단어/용어/도메인을 **각각 따로** 엑셀 다운로드해야 한다.
이를 **한 번의 클릭으로 단어·용어·도메인 3개 시트를 포함한 하나의 엑셀 파일**로 내려받는 기능을 추가한다.

## 현행 분석

### 현재 구조

```text
DictionaryWorkspace
  ├── WordTab     → [엑셀 다운로드] → GET /domains/download/excel  → 단어 사전.xlsx (1시트)
  ├── TermTab     → [엑셀 다운로드] → GET /terms/download/excel    → 용어 사전.xlsx (1시트)
  └── DomainTab   → [엑셀 다운로드] → GET /domains/download/excel  → 도메인 사전.xlsx (1시트)
```

- 각 탭에 **개별 다운로드** 버튼이 있고, 각각 별도의 엑셀 파일(1시트)을 생성한다.
- 백엔드: `DomainDictionaryExportService`, `TermDictionaryExportService`, `WordDictionaryExportService` 3개 서비스가 각각 단일 시트 `ExcelData`를 반환한다.
- 공통 포맷: `DictionaryWorkbookExportSupport`가 제목행, 헤더행, 본문 스타일, 동결 영역을 일관되게 생성한다.

### 기존 엑셀 시트 구성

| 시트 | 헤더 | 컬럼 수 |
|------|------|---------|
| 도메인 사전 | 도메인 그룹, 도메인명, 표준도메인명, 데이터 타입, 데이터 길이, 데이터 소수점 길이, 설명 | 7 |
| 용어 사전 | 논리명, 물리명, 도메인, 설명 | 4 |
| 단어 사전 | 논리명, 물리명, 설명 | 3 |
