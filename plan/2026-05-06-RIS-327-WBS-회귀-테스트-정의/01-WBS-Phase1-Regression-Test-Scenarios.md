# Phase 1 WBS 회귀 테스트 시나리오 정의

- 작성일: 2026-05-06
- 대상 이슈: RIS-327
- 관련 단계: Phase 5 (WBS+마일스톤), Phase 6.1 (WBS 작업공간 확장)

## 1. 개요
본 문서는 WBS 핵심 기능의 안정성을 보장하기 위한 회귀 테스트 범위와 상세 시나리오를 정의한다. 신규 기능(운영형 템플릿, 시프트 등) 추가 시 기존의 계층 구조 관리 및 기본 편집 기능이 손상되지 않았음을 검증하는 것을 목적으로 한다.

## 2. 테스트 범위
- **WBS 계층 구조**: 트리 구조 유지, Depth 제약(최대 3단계), 접기/펼치기
- **기본 CRUD**: 항목 생성(Root/Child), 정보 수정(기간, 진척률, M/M), 삭제
- **구조 변경**: 드래그 앤 드롭(DnD) 순서 변경, 부모 변경(Move)
- **인라인 편집**: 전용 작업공간에서의 인라인 항목 추가 및 담당자 배정
- **데이터 정합성**: 서버 데이터 저장 및 페이지 새로고침 후 상태 유지

## 3. 상세 테스트 시나리오

### 3.1. 계층 구조 및 트리 관리 (Tree & Hierarchy)
| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| T1.1 | 최상위(Root) WBS 항목 생성 | 목록 최하단 또는 지정된 위치에 새로운 Root 항목이 생성됨 |
| T1.2 | 하위(Child) WBS 항목 생성 (Depth 1~3) | 선택한 항목의 하위 계층으로 정상 생성되며 트리 인덴트가 적용됨 |
| T1.3 | 최대 Depth(3단계) 초과 생성 시도 | 3단계를 초과하는 하위 항목 생성 시도가 차단되거나 경고가 발생함 |
| T1.4 | 트리 접기/펼치기 | 부모 항목의 아이콘 클릭 시 하위 항목들이 정상적으로 토글됨 |

### 3.2. 항목 편집 및 관리 (Basic CRUD)
| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| C2.1 | WBS 항목 상세 정보 수정 | 이름, 시작일, 종료일, 진척률, 예상 M/M 수정 시 즉시 반영 및 저장됨 |
| C2.2 | 담당자(Assignee) 배정 및 해제 | 팀 멤버 목록에서 담당자 선택 시 행에 표시되며, 해제 시 정상 제거됨 |
| C2.3 | WBS 항목 삭제 | 삭제 시 목록에서 제거되며, 하위 항목이 있는 경우 함께 삭제되거나 안내됨 |
| C2.4 | 벌크(Bulk) 생성 (Text 기반) | 여러 줄의 텍스트 입력 시 각각의 WBS 항목으로 일괄 생성됨 |

### 3.3. 구조 및 순서 변경 (Reordering & Move)
| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| R3.1 | 동일 부모 내 DnD 순서 변경 | 항목을 드래그하여 순서를 바꿨을 때 시각적으로 정렬되고 서버에 저장됨 |
| R3.2 | 다른 부모로 항목 이동 (Move Dialog) | 이동 기능을 통해 부모가 변경되었을 때 계층 구조가 정확히 갱신됨 |
| R3.3 | 새로고침 후 순서 유지 확인 | 순서 변경 후 페이지를 새로고침해도 변경된 순서와 계층이 유지됨 |

### 3.4. 전용 작업공간 인라인 동작 (Workspace & Inline)
| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| I4.1 | 최하단 인라인 추가 행 사용 | 테이블 최하단의 '추가' 행을 통해 새 Root 항목이 즉시 생성됨 |
| I4.2 | 항목 사이 인라인 추가 버튼 사용 | 특정 항목 하단에 새 항목 추가 시 즉시 입력 폼이 나타나고 생성됨 |
| I4.3 | 상세 패널(Detail Panel) 연동 | 항목 클릭 시 우측 상세 패널이 열리며 모든 정보가 정확히 동기화됨 |

### 3.5. 데이터 및 제약 조건 (Data Integrity)
| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| D5.1 | 유효하지 않은 기간 설정 (시작 > 종료) | 시작일이 종료일보다 늦을 경우 에러 메시지가 표시되고 저장이 차단됨 |
| D5.2 | 진척률 범위 제한 (0~100%) | 0 미만 또는 100 초과 입력 시 유효성 검사가 동작함 |
| D5.3 | 프로젝트 요약 연동 | WBS 진척률 변경 시 프로젝트 사업 개요의 전체 진척률에 반영됨 |

## 4. 확인 사항
- 모든 테스트는 **ADMIN** 및 **MEMBER** 권한에서 수행되어야 함
- **GUEST** 권한인 경우 조회만 가능하고 모든 편집 기능(버튼 노출 등)이 차단되는지 확인
- 브라우저 호환성: Chrome, Safari 최신 버전 환경 확인
