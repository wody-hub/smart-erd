# WBS 작업 히스토리 관리 QA/승인 체크리스트

## 대상 이슈

- parent issue: [RIS-247](/RIS/issues/RIS-247)

## 기획 승인 체크

- 문서가 WBS 내부 필드가 아니라 독립 엔터티라는 정책에 합의했는가
- 개인 TODO 기본 비공개 / WBS 연결 시 일부 공유 정책에 합의했는가
- 태그 탭이 통합 검색이 아니라 태그 중심 허브라는 범위에 합의했는가
- 댓글과 활동 로그를 분리한다는 정책에 합의했는가

## Phase 1 QA 초안

- WBS 항목에서 새 문서를 생성하고 연결할 수 있다.
- WBS 항목에서 기존 문서를 연결/해제할 수 있다.
- 문서 태그가 태그 탭 목록에 반영된다.
- 태그 탭에서 태그별 문서 목록이 정확히 조회된다.
- 문서가 연결된 WBS 요약이 문서 목록에서 보인다.

## Phase 2 QA 초안

- WBS 항목별 댓글 작성/조회가 가능하다.
- 문서 연결/해제, 상태 변경 등 주요 이벤트가 활동 로그에 남는다.
- 댓글과 활동 로그가 서로 섞이지 않는다.

## Phase 3 QA 초안

- 개인 TODO는 작성자 본인에게만 기본 노출된다.
- WBS 미연결 TODO는 타인에게 보이지 않는다.
- WBS 연결 TODO는 공유 메타데이터가 WBS에서 보인다.
- TODO 연결/해제 후 노출 상태가 정책대로 전환된다.

## Phase 3 QA 실행 결과 (2026-04-28)

### 실행 증적

- `./gradlew test --tests 'com.smarterd.api.project.ProjectTodoControllerMvcTest' --tests 'com.smarterd.domain.pm.todo.service.ProjectTodoServiceTest'`
  - `ProjectTodoControllerMvcTest`: 5/5 pass
  - `ProjectTodoServiceTest`: 4/4 pass
- `cd client && npm run build`: pass

### 확인 포인트 결과

- [pass] 개인 TODO는 작성자 본인에게만 기본 노출된다.
  - 근거: `ProjectTodoServiceTest.getProjectTodo_rejectsNonOwner` 에서 비작성자 접근 시 `ERROR_ACCESS_DENIED_PROJECT_TODO_OWNER_ONLY` 확인
- [pass] WBS 미연결 TODO는 타인에게 보이지 않는다.
  - 근거: 공유 조회 경로가 `findByProjectAndLinkedWbsItem...` 기반이며, WBS 연결 투영 API는 `/wbs/{id}/todos` 에 한정(`ProjectTodoControllerMvcTest.getSharedTodoSummaries_returnsSharedProjection`)
- [pass] WBS 연결 TODO는 공유 메타데이터가 WBS에서 보인다.
  - 근거: `ProjectTodoControllerMvcTest.getSharedTodoSummaries_returnsSharedProjection` 에서 `ownerName`, `sharedDocuments[].visibility=PROJECT_SHARED` 검증
- [pass] TODO 연결/해제 후 노출 상태가 정책대로 전환된다.
  - 근거: `ProjectTodoControllerMvcTest.unlinkTodoFromWbs_returnsUpdatedTodo` 에서 해제 직후 `linkedWbsItemId` null 확인 + 공유 조회가 linked WBS 기준으로만 집계되는 서비스 계약 확인

### 비고

- 본 체크는 Stage 3 구현 완료 직후 자동화 경로 중심으로 수행했다.
- 수동 다계정 클릭 smoke(작성자/타사용자 동시 세션)는 후속 브라우저 회귀 창구에서 동일 포인트를 재확인할 수 있다.

## 승인 요청 시 확인할 질문

- 1차 구현 범위를 Phase 1까지만 자를지
- TODO를 프로젝트 허브 탭으로 먼저 넣을지, 사용자 개인 공간으로 분리할지
- 댓글 UI를 WBS 상세 패널 우선으로 둘지, 문서 상세와 동시 제공할지
