# RIS-295 QA 체크리스트

## 대상

- parent issue: [RIS-295](/RIS/issues/RIS-295)
- 선행 분석: [RIS-292](/RIS/issues/RIS-292)

## 사전 조건

- dependency 엔터티/API 구현이 완료되어 있어야 한다.
- Gantt에서 WBS/milestone/dependency가 함께 조회되어야 한다.
- milestone type/owner/readiness 확장이 반영된 테스트 데이터가 있어야 한다.

## dependency 도메인 체크

- 자기 자신을 predecessor/successor로 연결할 수 없다.
- 순환 dependency 생성이 차단된다.
- 다른 프로젝트 WBS와의 교차 연결이 차단된다.
- 중복 dependency 생성이 차단된다.
- dependency 삭제 후 관련 Gantt 링크가 즉시 사라진다.

## Gantt 체크

- dependency가 있는 WBS는 Gantt에서 링크와 함께 보인다.
- dependency 없는 WBS와 있는 WBS가 구분된다.
- milestone과 연결된 WBS chain이 시각적으로 추적 가능하다.
- 날짜 drag 수정이 기존처럼 동작하고 dependency 데이터는 손상되지 않는다.

## WBS 상세 체크

- WBS detail panel에서 predecessor/successor를 추가할 수 있다.
- dependency 제거가 가능하다.
- 다음 milestone 기준 blocking chain 요약이 올바르게 표시된다.
- compact tab과 dedicated page가 같은 dependency 상태를 보여준다.

## milestone 체크

- milestone 생성/수정 시 type 지정이 가능하다.
- owner 지정/해제가 가능하다.
- readiness note 저장/수정이 가능하다.
- milestone panel에서 type badge, owner, readiness, blocking count가 보인다.
- delayed 필터와 approval/deliverable 타입 필터가 기대대로 동작한다.

## rolling-wave 체크

- 다음 milestone까지의 WBS가 current wave로 식별된다.
- 이후 구간은 summary 성격으로 구분된다.
- 도움말/empty text가 `WBS=구조`, `Gantt=일정/의존성`, `Milestone=게이트` 원칙과 맞는다.

## 회귀 체크

- 기존 WBS CRUD 및 reorder가 유지된다.
- milestone 삭제 시 연결 정리 동작이 유지된다.
- WBS 상세 문서/댓글/활동 로그 기능이 깨지지 않는다.
- project query invalidation 이후 WBS/Gantt/Milestone이 함께 최신화된다.
