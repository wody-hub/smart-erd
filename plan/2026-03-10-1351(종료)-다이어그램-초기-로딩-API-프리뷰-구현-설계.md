# 2026-03-10-1351(종료) 다이어그램 초기 로딩 — API Preview 구현 설계

작성일: 2026-03-10 13:51
선행 분석: `2026-03-10-1345(종료)-다이어그램-초기-로딩-성능-개선-분석.md`

## 목표

다이어그램 진입 시 API 응답의 JSON content를 **Y.Doc을 거치지 않고 Zustand에 직접 주입**하여
캔버스를 즉시 표시한다. WS 스냅샷이 도착하면 Y.Doc observeDeep가 자동으로 Zustand를 교체하고
편집 모드를 활성화한다.

### 개선 효과

```text
Before: API(500ms) → WS연결(300ms) → 스냅샷(500-1000ms) → 변환(200ms) = 1.5~3초 빈 캔버스
After:  API(500ms) → 즉시 프리뷰 표시(30ms) = ~530ms만에 그래프 가시화
```

---

## 핵심 원칙

1. **Y.Doc을 건드리지 않는다** — JSON preview는 Zustand에만 주입. CRDT 충돌 불가능.
2. **프리뷰 중 편집 불가** — Y.Doc이 비어있으므로 편집하면 스냅샷 도착 시 유실됨. 오히려 장점: Y.Doc과 이격 없음.
3. **기존 WS 흐름 변경 없음** — WS 연결 → SNAPSHOT_REQUEST → SNAPSHOT_RESPONSE → Y.applyUpdate 경로 유지.

---

## 데이터 흐름

```text
[API 응답]
    │
    ├─ content(JSON) ──→ loadPreview() ──→ Zustand { nodes, edges, groups }
    │                                         │
    │                                         └──→ 캔버스 즉시 렌더 (읽기 전용)
    │
    └─ hasYdocSnapshot=true
         │
         ├─ Y.Doc (빈 상태) ──→ initYDoc() ──→ observeDeep 등록
         │                                       │
         ├─ WS 연결 → SNAPSHOT_REQUEST            │
         │   └─ SNAPSHOT_RESPONSE × N ──→ Y.applyUpdate()
         │                                       │
         │                                       ▼
         │                            observeDeep 트리거
         │                                       │
         │                                       ▼
         │                          Zustand { nodes, edges, groups } ← 최신 데이터로 교체
         │                                       │
         └─ previewExitObserver ──→ isPreviewMode = false
                                                  │
                                                  ▼
                                            편집 활성화 ✅
```

## 상세 설계

### 1. `loadPreview(json: string)` — canvasSyncActions.ts

Y.Doc을 거치지 않고 JSON을 파싱하여 Zustand에 직접 주입한다.

```typescript
loadPreview: (json: string) => {
  try {
    const parsed = JSON.parse(json) as {
      nodes?: Node<TableNodeData>[];
      edges?: Edge[];
      groups?: TableGroup[];
    };
    set({
      nodes: Array.isArray(parsed.nodes) ? parsed.nodes : [],
      edges: Array.isArray(parsed.edges)
        ? parsed.edges.map((e: Edge) => ({ ...e, type: e.type ?? 'erdRelation' }))
        : [],
      groups: Array.isArray(parsed.groups) ? parsed.groups : [],
    });
  } catch {
    // JSON 파싱 실패 시 무시 — 빈 캔버스 유지
  }
},
```

**주의:**

- `ydoc` 필드는 건드리지 않는다.
- `lastBackupHash`도 변경하지 않는다 (preview는 백업 대상이 아님).
- `serialize()` 직렬화에 영향 없음 — `serialize()`는 Y.Doc에서 읽음.
- edge `type`이 누락된 비정상 JSON에 대비해 `'erdRelation'` 기본값을 보장한다.

**auto-backup 안전성:**

`useAutoBackup`은 `hasLocalChangeRef`로 로컬 변경만 백업 대상으로 감지하며,
WS 스냅샷(`origin='remote'`)은 로컬 변경으로 인식하지 않는다.
따라서 프리뷰 중 빈 Y.Doc이 서버에 저장되는 경로는 없다.

### 2. `useYjsCollaboration` — isPreviewMode 관리

```typescript
export function useYjsCollaboration(
  diagram: DiagramDetail | undefined,
  diagramId: string | undefined,
): UseYjsCollaborationReturn {
  const providerRef = useRef<YjsProvider | null>(null);
  const [isPreviewMode, setIsPreviewMode] = useState(false);  // ← 추가

  // ... (기존 store selector 동일)
  const loadPreview = useCanvasStore((s) => s.loadPreview);    // ← 추가

  useEffect(() => {
    if (!diagram || !diagramId) return;

    const ydoc = new Y.Doc();

    // 레거시: hasYdocSnapshot=false → JSON → Y.Doc 직접 마이그레이션 (기존과 동일)
    if (diagram.content && !diagram.hasYdocSnapshot) {
      migrateJsonToYDoc(ydoc, diagram.content);
    }

    // Y.Doc → Zustand 연결 (observeDeep 등록)
    initYDoc(ydoc);

    // ★ 신규: hasYdocSnapshot=true → API JSON으로 프리뷰 즉시 표시
    let previewExitObserver: (() => void) | null = null;
    if (diagram.hasYdocSnapshot && diagram.content) {
      loadPreview(diagram.content);   // Zustand에 직접 주입
      setIsPreviewMode(true);

      // Y.Doc에 데이터가 들어오면 프리뷰 모드 해제
      const tablesMap = getTablesMap(ydoc);
      previewExitObserver = () => {
        if (tablesMap.size > 0) {
          tablesMap.unobserveDeep(previewExitObserver!);
          previewExitObserver = null;
          setIsPreviewMode(false);
        }
      };
      tablesMap.observeDeep(previewExitObserver);
    }

    // YjsProvider 연결 (기존과 동일)
    const provider = new YjsProvider(ydoc, { diagramId, getTicket });
    // ... (콜백 등록 동일)
    provider.connect();
    providerRef.current = provider;

    // WS 스냅샷 미도착 폴백 (기존과 동일, 5초)
    let snapshotFallbackTimer: ReturnType<typeof setTimeout> | null = null;
    if (diagram.hasYdocSnapshot && diagram.content) {
      snapshotFallbackTimer = setTimeout(() => {
        snapshotFallbackTimer = null;
        if (getTablesMap(ydoc).size === 0) {
          ydoc.transact(() => migrateJsonToYDoc(ydoc, diagram.content!), 'remote');
          // → observeDeep 트리거 → Zustand 교체
          // → previewExitObserver 트리거 → isPreviewMode=false
        }
      }, WS_SNAPSHOT_FALLBACK_MS);
    }

    return () => {
      // previewExitObserver 정리
      if (previewExitObserver) {
        getTablesMap(ydoc).unobserveDeep(previewExitObserver);
      }
      setIsPreviewMode(false);
      // ... (기존 cleanup 동일)
    };
  }, [diagramId, diagram?.id]);

  return { providerRef, isPreviewMode };  // ← isPreviewMode 추가
}
```

### 3. `DiagramPage.tsx` — 편집 잠금 연동

```typescript
// useYjsCollaboration 반환값에 isPreviewMode 추가
const { providerRef, isPreviewMode } = useYjsCollaboration(diagram, diagramId);

// ERDCanvas에 전달하는 canEdit를 isPreviewMode로 제한
<ERDCanvas
  // ...
  canEdit={canEdit && !isPreviewMode}
  // ...
/>
```

오버레이 로직은 변경 없음:

- preview 로드 → `hasRenderableGraph = true` → `showOverlay = false` → 오버레이 즉시 해제
- 즉, 프리뷰가 로드되면 오버레이도 사라지고 캔버스가 보임 (단, 편집은 잠금)

| 항목             | 이전 시도 (장애 발생)                | 이번 설계                            |
| ---------------- | ------------------------------------ | ------------------------------------ |
