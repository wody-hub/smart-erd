# 05. UI 레이아웃

```text
┌──────────────────────────────────────────────────────────────────────────┐
│  [뒤로] 프로젝트명 / 문서명                     [공유] [내보내기] [저장]   │

│ 아웃라인    │    Monaco 에디터      │    라이브 프리뷰       │ 메타·속성      │

## 4-패널 구성

### 1. 아웃라인 패널 (좌)

```text
[아웃라인]
─────────────────
▶ API 설계 문서         ← h1 (접기/펼치기)
  ├─ 개요               ← h2
  ├─ 엔드포인트          ← h2
  │  ├─ 사용자 API       ← h3
  │  └─ 주문 API        ← h3
  └─ 인증               ← h2
     ├─ JWT 토큰        ← h3
     └─ OAuth2          ← h3

─────────────────
참여자:
  [👤A 홍길동] 섹션: 개요
  [👤B 김철수] 섹션: 인증      🔒
```

- 항목 클릭: 에디터와 프리뷰에서 해당 섹션으로 스크롤
- 항목 드래그: 섹션 순서 변경 (section.move)
- 현재 커서 위치의 섹션 하이라이트 (활성 표시)
- 잠긴 섹션에 🔒 아이콘 표시
- 다른 참여자가 편집 중인 섹션 표시

### 2. Monaco 에디터 (중좌)

```text
마크다운 텍스트 편집 영역:
  - 마크다운 구문 하이라이팅
  - 줄 번호 표시
  - 자동 완성 (heading, 링크, 이미지)
  - 포맷팅 단축키 (Cmd+B: Bold, Cmd+I: Italic 등)
  - 원격 참여자 커서 표시 (색상 라벨)
  - 원격 참여자 선택 영역 하이라이트
```

### 3. 라이브 프리뷰 (중우)

```text
마크다운 → HTML 렌더링 결과:
  - remark → rehype → HTML 변환 결과 표시
  - 코드 블록 구문 하이라이팅
  - 테이블 스타일 적용
  - 이미지 렌더링 (asset:// → 실제 URL)
  - 에디터 스크롤과 동기화 (같은 섹션 위치)
  - 체크리스트 체크/언체크 (프리뷰에서도 가능)
```

### 4. 메타·속성 패널 (우)

```text
[Frontmatter]
─────────────────
제목: [API 설계 문서    ]
작성자: [홍길동         ]
날짜: [2026-03-26      ]
상태: [draft         ▼]
태그: [api] [rest] [+]

─────────────────
[문서 설정]
프리뷰 모드: [분할 뷰  ▼]
자동저장: [✓]
줄 바꿈: [✓]
글꼴 크기: [14px      ▼]
```

Frontmatter 폼 편집 시 `frontmatter.update` 커맨드가 생성되어 Y.Map("frontmatter")에 반영된다. 에디터 본문의 `---` 블록도 동시에 갱신된다.

## 포맷팅 툴바

```text
[B] [I] [~~] [H▼] [`] [```] [─] [🔗] [📷] [☑] [📊] | [분할] [에디터] [프리뷰]
```

| 버튼 | 기능 | 삽입되는 구문 | 단축키 |
|---|---|---|---|
| B | Bold | `**text**` | Cmd+B |
| I | Italic | `*text*` | Cmd+I |
| ~~ | Strikethrough | `~~text~~` | Cmd+Shift+X |
| H▼ | Heading (드롭다운) | `# ` ~ `###### ` | Cmd+1~6 |
| `` ` `` | Inline Code | `` `code` `` | Cmd+E |
| ``` | Code Block | ` ```lang\n...\n``` ` | Cmd+Shift+E |
| ─ | Horizontal Rule | `---` | — |
| 🔗 | Link | `[text](url)` | Cmd+K |
| 📷 | Image | `![alt](url)` 또는 asset 업로드 | — |
| ☑ | Task List | `- [ ] task` | — |
| 📊 | Table | 테이블 삽입 다이얼로그 | — |

### 포맷팅 동작 규칙

```text
텍스트 선택 후 Bold 클릭:
  선택된 "hello" → "**hello**" 로 감싸기

텍스트 선택 없이 Bold 클릭:
  커서 위치에 "**커서**" 삽입, 커서를 ** 사이에 위치

이미 Bold인 텍스트 선택 후 Bold 클릭:
  "**hello**" → "hello" (토글)
```

## 프리뷰 모드

| 모드 | 설명 | 레이아웃 |
|---|---|---|
| 분할 뷰 (기본) | 에디터와 프리뷰 좌우 분할 | [에디터 50%] [프리뷰 50%] |
| 에디터 전체 | 프리뷰 숨기고 에디터만 표시 | [에디터 100%] |
| 프리뷰 전체 | 에디터 숨기고 프리뷰만 표시 | [프리뷰 100%] |

프리뷰 모드는 우측 상단 토글 버튼 또는 단축키로 전환한다.

### 에디터-프리뷰 스크롤 동기화

```text
동기화 전략:
  1. 에디터 스크롤 시 → 현재 커서 라인의 heading 기반 섹션 식별
  2. 프리뷰에서 해당 섹션의 anchor를 찾아 스크롤
  3. 프리뷰 스크롤 시 → 역방향으로 에디터 동기화 (선택적)

정확도:
  - heading 기반 섹션 단위 동기화 (줄 단위보다 안정적)
  - 매우 긴 섹션 내에서는 비례 스크롤 추정
```

## 하단 상태 바

```text
├──────────────────────────────────────────────────────────────────────────┤
│ Ln 15, Col 8 │ Section: 엔드포인트 │ ● dirty-valid │ 자동저장: 30초 전   │
└──────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 표시 내용 |
|---|---|
| 커서 위치 | `Ln {line}, Col {column}` |
| 현재 섹션 | 커서가 위치한 heading 기반 섹션 이름 |
| DraftState | `● clean` / `● dirty-valid` / `● dirty-invalid` / `⚠ remote-pending` |
| 자동저장 | `자동저장: {n}초 전` / `저장됨` / `저장 중...` |

### DraftState 상태별 표시

| DraftState | 아이콘 | 색상 | 텍스트 |
|---|---|---|---|
| clean | ● | 초록 | 저장됨 |
| dirty-valid | ● | 노랑 | 변경됨 |
| dirty-invalid | ● | 빨강 | 구문 오류 (diagnostics 수) |
| remote-pending | ⚠ | 주황 | 원격 변경 있음 |

## 협업 UI

### 원격 커서 표시

```text
Monaco 에디터 내:
  - 다른 참여자의 커서를 색상 라벨로 표시
  - 라벨에 참여자 이름 표시 (2초 후 자동 숨김, hover 시 재표시)
  - 각 참여자에 고유 색상 할당

예시:
  Line 15: 여기에 텍스트를 작성합니다.|     ← 내 커서 (기본)
  Line 23: API 응답은 JSON 형식|김철수|    ← 김철수의 커서 (파란색)
```

### 원격 선택 영역 하이라이트

```text
다른 참여자가 텍스트를 선택 중인 영역을 반투명 색상으로 하이라이트:
  - 참여자 커서 색상과 동일한 색상의 배경
  - opacity: 0.15 로 본문 가독성 유지
```

### 아웃라인 섹션 편집 상태

```text
아웃라인 패널에서 각 섹션의 편집 상태를 표시:

  ├─ 개요                    ← 편집 중인 사람 없음
  ├─ 엔드포인트 [👤A]         ← 홍길동이 편집 중 (커서 위치 기반)
  │  ├─ 사용자 API
  │  └─ 주문 API
  └─ 인증 🔒 [👤B]           ← 김철수가 편집 중 + scope lock 보유
```

### 잠긴 섹션 진입 시 동작

```text
다른 참여자가 scope lock을 보유한 섹션에 커서를 이동하면:

  1. 에디터에서 해당 섹션 영역을 읽기 전용으로 표시
  2. 상태 바에 "이 섹션은 김철수님이 편집 중입니다" 표시
  3. 해당 영역의 배경색을 약간 변경 (읽기 전용 표시)
  4. 타이핑 시도 시 "편집 불가" 피드백
```

### remote-pending 알림 UI

```text
┌────────────────────────────────────────────────────────────┐
│ ⚠ 다른 참여자가 현재 편집 중인 섹션을 수정했습니다.           │
│                                                            │
│ 섹션: "엔드포인트"                                          │
│ 수정자: 김철수                                              │
│                                                            │
│ [원격 변경 수락]  [내 편집 유지 + 리베이스]  [나중에 비교]     │
└────────────────────────────────────────────────────────────┘
```

## 이미지 삽입 인터랙션

### 드래그&드롭

```text
1. 이미지 파일을 에디터 영역으로 드래그
2. 드롭 위치에 업로드 progress indicator 표시
3. AssetRuntime으로 이미지 업로드
4. 업로드 완료 후 ![이미지](asset://asset-id) 구문 자동 삽입
5. 프리뷰에 이미지 즉시 표시
```

### 클립보드 붙여넣기

```text
1. 이미지를 복사한 상태에서 에디터에 Cmd+V
2. 클립보드에서 이미지 데이터 추출
3. AssetRuntime으로 업로드
4. 커서 위치에 ![이미지](asset://asset-id) 구문 삽입
```

### 툴바 이미지 버튼

```text
1. 📷 버튼 클릭
2. 파일 선택 다이얼로그 표시
3. 이미지 파일 선택
4. AssetRuntime으로 업로드
5. 커서 위치에 ![alt](asset://asset-id) 구문 삽입
   (alt 텍스트 입력 프롬프트 표시)
```

## 테이블 삽입 다이얼로그

```text
┌──────────────────────────┐
│ 테이블 삽입                │
│                          │
│ 행: [3    ]  열: [4    ]  │
│ 헤더 행: [✓]              │
│ 정렬: [왼쪽 ▼]            │
│                          │
│ 미리보기:                  │
│ | 열1  | 열2  | 열3  | 열4  |
│ |------|------|------|------|
│ |      |      |      |      |
│ |      |      |      |      |
│                          │
│ [취소]           [삽입]   │
└──────────────────────────┘
```

삽입 시 마크다운 테이블 구문이 커서 위치에 생성된다.

## 반응형 레이아웃

```text
넓은 화면 (1440px+):
  [아웃라인 200px] [에디터 flex] [프리뷰 flex] [메타 280px]

중간 화면 (1024~1440px):
  아웃라인 접기 → [에디터 flex] [프리뷰 flex] [메타 280px]

좁은 화면 (~1024px):
  에디터/프리뷰 탭 전환 → [에디터 or 프리뷰 100%]
  메타 패널 오버레이
```
