## 잔여 작업 목록

### P1 — 기능 완성 (필수)

#### T1. 프론트엔드 Export API 연결

- **현재 상태:** `MarkdownToolbar.tsx`에 `onExport` 핸들러가 존재하지만, `diagramApi.ts`에 실제 POST `/exports` 호출 함수가 없다
- **백엔드:** `DiagramController`의 `/exports` 엔드포인트는 이미 구현 완료 (`ExportDocumentRequest` DTO 포함)
- **작업 범위:**
  1. `client/src/api/diagramApi.ts`에 `exportDocument()` 함수 추가
  2. `MarkdownDocumentPage.tsx` 또는 `MarkdownToolbar.tsx`에서 export 호출 연결
  3. 파일 다운로드 처리 (Blob → anchor download)

#### T2. 백엔드 통합 테스트

- **현재 상태:** `MarkdownTemplateServiceTest` 단위 테스트만 존재
- **작업 범위:**
  1. `DiagramControllerMvcTest`에 markdown 문서 생성 테스트 추가 (pluginId=MARKDOWN, templateKey 지정)
  2. `DiagramControllerTest`에 markdown export 통합 테스트 추가
  3. pluginId 유효성 검증 테스트 (잘못된 pluginId → 400 에러)

---

### P2 — 품질 보강 (권장)

#### T3. Monaco 에디터 마크다운 전용 설정 검증

- **현재 상태:** Monaco가 마크다운 모드로 동작하지만, 전용 설정(word wrap, minimap, line numbers 등)이 최적화되었는지 미확인
- **작업 범위:**
  1. `MarkdownDocumentPage.tsx`의 Monaco options 검토
  2. 마크다운 편집에 적합한 설정 확인 (wordWrap: on, minimap: off, lineNumbers: off 등)
  3. 다크모드 테마 일관성 확인

#### T4. 모바일/태블릿 UI 실제 검증

- **현재 상태:** `MarkdownEditorShell.tsx`에 adaptive 디자인이 구현되어 있으나, 실제 디바이스/뷰포트 테스트 미실시
- **작업 범위:**
  1. 태블릿(768~1023px): Write/Split/Preview 탭 전환 동작 확인
  2. 모바일(<768px): 3탭 전환, Outline/Info bottom sheet 동작 확인
  3. 터치 인터랙션 (스크롤, 탭, drawer 제스처) 확인

#### T5. Collaboration 오류 복구 엣지 케이스

- **현재 상태:** `use-markdown-document-session.ts`에 snapshot 복구 로직이 있으나, 엣지 케이스 검증 부족
- **작업 범위:**
  1. 네트워크 끊김 후 재연결 시 Y.Text 동기화 무결성 확인
  2. 동시 편집 중 한 쪽 브라우저 강제 종료 후 복구 시나리오
  3. remote-pending 상태에서 3가지 선택 후 상태 정합성 검증

### P3 — 최적화 (후속)

#### T6. 대용량 문서 성능 최적화

- **현재 상태:** `parseMarkdownBuffer()`가 매 호출마다 전체 재파싱 수행 (1단계 설계 의도)
- **작업 범위:**
  1. 대용량 문서(500줄+) 파싱 시간 측정
  2. 필요 시 증분 파싱 도입 (섹션 단위 `markdown:section-update` — 로드맵 2단계 → 5단계 진화 경로)
  3. 프리뷰 렌더링 가상 스크롤 검토

#### T7. Swagger/OpenAPI 문서화 보강

- **현재 상태:** `/exports` 엔드포인트에 `@Operation` 주석이 있으나, 요청/응답 예시 부족
- **작업 범위:**
  1. `ExportDocumentRequest` 필드별 `@Schema` 예시 추가
  2. markdown 문서 생성 시 `CreateDiagramRequest`의 pluginId/templateKey 예시 보강
