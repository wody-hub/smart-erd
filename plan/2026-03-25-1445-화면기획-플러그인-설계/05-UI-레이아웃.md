
## 좌측 패널

좌측 패널은 두 개의 탭으로 구성된다.

### 화면 탭

```text
[화면]  [라이브러리]
─────────────────
[+ 새 화면]

📄 로그인 화면          ← 현재 활성 (하이라이트)
📄 회원가입 화면
📄 메인 대시보드
📄 사용자 관리 화면
📄 사용자 상세 화면
📄 주문 관리 화면
```

- 화면 클릭: 해당 화면을 캔버스에 표시
- 화면 드래그: 순서 변경
- 화면 우클릭: 이름 변경, 복제, 삭제
- 화면 썸네일: 축소 미리보기 표시 (선택적, 2단계)

### 라이브러리 탭

```text
[화면]  [라이브러리]
─────────────────
[🔍 컴포넌트 검색]

[+ 새 컴포넌트]

📁 레이아웃
  ├─ ◆ GNB
  ├─ ◆ LNB
  ├─ ◆ 탭 메뉴
  └─ ◆ 브레드크럼

📁 표
  ├─ ◆ 데이터 테이블
  ├─ ◆ 심플 테이블
  └─ ◆ 카드 리스트

📁 폼
  ├─ ◆ 로그인 폼
  ├─ ◆ 검색 바
  └─ ◆ 필터 패널

📁 입력
  ├─ ◆ 텍스트 입력
  ├─ ◆ 드롭다운
  └─ ◆ 체크박스 그룹
```

- 컴포넌트 드래그: 캔버스로 드래그&드롭하여 인스턴스 생성
- 컴포넌트 더블클릭: 컴포넌트 편집 모드 진입
- 컴포넌트 우클릭: 이름 변경, 복제, 삭제
- 카테고리 접기/펼치기: 아코디언
- 검색: 이름 기반 필터링

## 캔버스 영역

### 기본 인터랙션

| 동작 | 결과 |
|---|---|
| 빈 영역 클릭 | 선택 해제 |
| 요소 클릭 | 단일 선택 |
| Shift + 클릭 | 다중 선택에 추가/제거 |
| 드래그 (빈 영역) | 범위 선택 |
| 드래그 (선택된 요소) | 이동 |
| 요소 모서리 드래그 | 리사이즈 |
| 스크롤 | 캔버스 팬 |
| Cmd/Ctrl + 스크롤 | 줌 인/아웃 |
| 더블클릭 (인스턴스) | 컴포넌트 편집 모드 진입 |
| Escape | 선택 해제 또는 편집 모드 나가기 |
| Delete/Backspace | 선택된 요소 삭제 |
| Cmd/Ctrl + C/V | 복사/붙여넣기 |
| Cmd/Ctrl + D | 복제 |
| Cmd/Ctrl + Z/Y | Undo/Redo |

### 캔버스 도구 모음

```text
[선택 도구] [사각형] [텍스트] [구분선] [이미지] [주석] | [그리드 표시] [스냅]
```

| 도구 | 기능 |
|---|---|
| 선택 도구 (V) | 기본. 요소 선택/이동/리사이즈 |
| 사각형 (R) | PrimitiveRectangle 생성 |
| 텍스트 (T) | PrimitiveText 생성 |
| 구분선 (L) | PrimitiveDivider 생성 |
| 이미지 (I) | PrimitiveImage placeholder 생성 |
| 주석 (N) | Annotation 생성 |
| 그리드 표시 | 그리드 오버레이 토글 |
| 스냅 | 요소 정렬 스냅 토글 |

### 컴포넌트 편집 모드

마스터 컴포넌트를 편집하는 특수 모드다.

```text
일반 모드:
  → 화면 내 인스턴스와 독립 요소를 편집
  → 인스턴스는 오버라이드만 가능 (내부 구조 변경 불가)

컴포넌트 편집 모드 (더블클릭 또는 라이브러리에서 편집):
  → 마스터 컴포넌트의 children을 직접 편집
  → 캔버스가 컴포넌트 내부만 표시
  → 상단에 "◆ GNB 편집 중" 브레드크럼 표시
  → Escape 또는 브레드크럼 클릭으로 일반 모드로 복귀
  → 편집 내용은 즉시 모든 인스턴스에 반영
```

```text
┌─────────────────────────────────────────────────────┐
│  ← 사용자 관리 화면 / ◆ GNB 편집 중                    │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌─────────────────────────────────────────────┐    │
│  │ [로고]  [대시보드]  [사용자]  [주문]  [설정]   │    │
│  │                              ← 새 메뉴 추가   │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  속성 정의:                                          │
│  ├─ menuItems: ["대시보드","사용자","주문","설정"]      │
│  ├─ activeMenu: "대시보드" (enum)                    │
│  └─ showLogo: true (boolean)                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 우측 패널

### 선택 없음 → 화면 속성

```text
[화면 속성]
─────────────────
이름: 사용자 관리 화면
설명: 관리자가 사용자 목록을 조회하고 관리하는 화면

크기: [데스크톱 ▼]
  너비: 1440
  높이: 900

배경색: [────────]

[화면 흐름]
  → 사용자 상세 화면: "행 클릭 시"
  → 사용자 등록 화면: "추가 버튼 클릭 시"
  [+ 흐름 추가]
```

### 인스턴스 선택 → 인스턴스 속성

```text
[인스턴스 속성]
─────────────────
컴포넌트: ◆ 데이터 테이블
[원본으로 이동]  [Detach]

[배리언트]
  상태: [데이터있음 ▼]
  크기: [기본 ▼]

[속성 오버라이드]
  제목: [사용자 목록] ↩      ← 오버라이드됨 (리셋 아이콘)
  컬럼: [#, 이름, 이메일, ...] ↩
  행 수: 5                    ← 마스터 원본
  페이지네이션: ✓              ← 마스터 원본

[배치]
  X: 240   Y: 120
  너비: 960  높이: 600
  [🔒 위치 고정]
```

### 독립 요소 선택 → 요소 속성

```text
[요소 속성]
─────────────────
유형: 사각형

[스타일]
  채우기: [────────]
  테두리: [────────] 1px solid
  모서리: 8px

[텍스트] (텍스트 요소인 경우)
  내용: "제목 텍스트"
  크기: 16px
  두께: [Bold ▼]
  정렬: [왼쪽 ▼]

[배치]
  X: 100   Y: 50
  너비: 200  높이: 40
```

### 마스터 컴포넌트 편집 → 컴포넌트 속성

```text
[컴포넌트 속성]
─────────────────
이름: 데이터 테이블
카테고리: [표 ▼]
설명: 페이지네이션이 포함된 데이터 목록

[속성 정의]
  ├─ title (text) = "제목"       [편집] [삭제]
  ├─ columns (text-list)          [편집] [삭제]
  ├─ rowCount (number, 1~50) = 5  [편집] [삭제]
  └─ showPagination (boolean) = true [편집] [삭제]
  [+ 속성 추가]

[배리언트]
  축: 상태 [데이터있음, 비어있음, 로딩중, 에러]
  축: 크기 [기본, 컴팩트]
  [+ 축 추가]

[슬롯]
  ├─ 헤더 액션: ◆ 검색+버튼 (카테고리: 폼, 버튼)
  └─ 행 액션: ◆ 버튼 그룹 (카테고리: 버튼)
  [+ 슬롯 추가]

[사용 현황]
  이 컴포넌트를 사용하는 화면: 4개
  ├─ 📄 사용자 관리 화면
  ├─ 📄 주문 관리 화면
  ├─ 📄 상품 관리 화면
  └─ 📄 재고 관리 화면
```

## 하단 바

```text
├──────────────────────────────────────────────────────────────┤
│ [주석 모드]  최근 주석: "ADMIN만 삭제 버튼 노출"  [흐름도 보기] │
└──────────────────────────────────────────────────────────────┘
```

- **주석 모드**: 토글. 활성 시 주석 레이어 표시 + 주석 추가 가능
- **최근 주석**: 현재 화면의 주석 미리보기
- **흐름도 보기**: 화면 흐름도 뷰로 전환

## 흐름도 뷰

흐름도 보기를 클릭하면 전체 화면 흐름을 시각적으로 표시하는 모드로 전환된다.

```text
┌─────────────────────────────────────────────────────────────────┐
│  [← 화면 편집으로 돌아가기]              [자동 배치] [내보내기]     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────┐    로그인 성공    ┌──────────────┐               │
│   │ 📄 로그인  │ ──────────────► │ 📄 대시보드    │               │
│   └──────────┘                  └──────┬───────┘               │
│         │                              │                        │
│     회원가입                    ┌───────┼────────┐              │
│         ▼                     ▼       ▼        ▼              │
│   ┌──────────┐         ┌─────────┐┌────────┐┌────────┐        │
│   │ 📄 회원가입│         │📄 사용자 ││📄 주문  ││📄 프로필│        │
│   └──────────┘         └────┬────┘└────────┘└────────┘        │
│                             ▼                                   │
│                       ┌─────────┐                               │
│                       │📄 상세   │                               │
│                       └─────────┘                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

- 화면 노드를 클릭하면 해당 화면으로 이동
- 화면 노드를 드래그하면 위치 조정 가능
- 자동 배치: dagre 레이아웃 적용
- 흐름 선 위에 트리거 설명 표시

## 협업 시 UI 표시

### Presence 표시

```text
캔버스 위:
  - 다른 참여자의 커서 (이름 라벨 + 색상)
  - 다른 참여자가 선택한 요소에 색상 테두리

화면 탭:
  - 현재 같은 화면을 보고 있는 참여자 아바타 표시
  📄 사용자 관리 화면  [👤A] [👤B]

컴포넌트 편집 모드:
  - 다른 참여자가 같은 컴포넌트를 편집 중이면 경고
  "◆ GNB — 김철수님이 편집 중"
```

### Lock 표시

```text
컴포넌트 락:
  라이브러리에서 잠긴 컴포넌트에 🔒 아이콘
  ◆ GNB 🔒 (김철수)

화면 락:
  화면 탭에서 잠긴 화면에 🔒 아이콘
  📄 사용자 관리 🔒 (박영희)

  잠긴 화면/컴포넌트 진입 시:
  → 읽기 전용 모드 + "현재 [이름]님이 편집 중입니다" 안내
```
