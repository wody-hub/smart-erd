# 01. 도메인 모델

## 전체 엔티티 관계

```text
[Project]
  └─< [ScreenSpecDocument]
        ├─ [ComponentLibrary]
        │    └─< [MasterComponent]
        │          ├─< [ComponentNode]     (트리 구조)
        │          ├─< [PropertyDefinition]
        │          ├─< [VariantAxis]
        │          └─< [VariantSet]
        │
        └─< [Screen]
              ├─< [ComponentInstance]
              │     └─< [Override]
              ├─< [PrimitiveElement]       (독립 도형/텍스트)
              ├─< [Annotation]             (기획 메모)
              └─< [ScreenLink]             (화면 간 연결)
```

## 1. 최상위 문서

```typescript
interface ScreenSpecDocument {
  documentId: string;
  name: string;
  library: ComponentLibrary;
  screens: Screen[];
  screenOrder: string[];         // 화면 정렬 순서 (ID 배열)
  globalStyles: GlobalStyleSet;  // 공통 스타일 정의
}
```

화면기획 문서는 하나의 프로젝트 내에서 독립된 문서 단위다.
ERD 다이어그램이 `Diagram` 엔티티에 매핑되듯이, 화면기획 문서는 동일한 `Document` 엔티티에 `pluginId: 'screen-spec'`으로 매핑된다.

## 2. 컴포넌트 라이브러리

```typescript
interface ComponentLibrary {
  categories: ComponentCategory[];
  components: MasterComponent[];
}

interface ComponentCategory {
  id: string;
  name: string;      // "표", "폼", "네비게이션", "입력", "피드백", "레이아웃"
  sortOrder: number;
}
```

라이브러리는 문서 내에 포함된다. 프로젝트 전체에서 공유하는 글로벌 라이브러리는 이번 범위에서 제외하되, 구조상 나중에 분리할 수 있도록 ID 기반 참조를 유지한다.

## 3. 마스터 컴포넌트

```typescript
interface MasterComponent {
  id: string;
  name: string;                       // "목록 테이블"
  categoryId: string;                 // ComponentCategory.id 참조
  description: string;                // "페이지네이션이 포함된 데이터 목록"

  children: ComponentNode[];          // 내부 구조 트리

  properties: PropertyDefinition[];   // 외부에 노출하는 속성
  variantAxes: VariantAxis[];         // 배리언트 축 정의
  variants: VariantSet[];             // 배리언트별 차이점

  layout: LayoutRule;                 // 내부 레이아웃 규칙
  defaultSize: Size;                  // 기본 크기
}
```

### 마스터 컴포넌트 예시

```text
◆ 목록 테이블
├─ 카테고리: 표
├─ 속성 정의:
│   ├─ title (text) = "제목"
│   ├─ columns (text[]) = ["#", "이름", "설명", "작업"]
│   ├─ rowCount (number) = 5
│   └─ showPagination (boolean) = true
├─ 배리언트 축:
│   └─ 상태: [데이터있음, 비어있음, 로딩중]
└─ children:
    ├─ [Group] 헤더 영역
    │   ├─ [Text] title (property binding: title)
    │   └─ [Slot] 헤더 액션 (기본: 검색+버튼)
    ├─ [Group] 테이블 본문
    │   ├─ [Group] 컬럼 헤더 (property binding: columns)
    │   └─ [Group] 데이터 행 × rowCount
    └─ [Group] 페이지네이션 (visible binding: showPagination)
```

## 4. 컴포넌트 노드

컴포넌트의 내부를 구성하는 원자 요소다.

```typescript
type ComponentNode =
  | TextNode
  | RectangleNode
  | IconNode
  | ImagePlaceholderNode
  | DividerNode
  | SlotNode
  | GroupNode;

interface NodeBase {
  id: string;
  name: string;
  position: Position;
  size: Size;
  visible: boolean;
  style: NodeStyle;
  propertyBinding?: string;    // PropertyDefinition.name에 바인딩
}

interface TextNode extends NodeBase {
  type: 'text';
  content: string;
  textStyle: TextStyle;
}

interface RectangleNode extends NodeBase {
  type: 'rectangle';
  cornerRadius: number;
  fill: FillStyle;
  stroke: StrokeStyle;
}

interface IconNode extends NodeBase {
  type: 'icon';
  iconName: string;            // 내장 아이콘 라이브러리 참조
}

interface ImagePlaceholderNode extends NodeBase {
  type: 'image-placeholder';
  label: string;               // "프로필 이미지", "배너 이미지"
  assetRef?: string;           // AssetRuntime 참조 (선택)
}

interface DividerNode extends NodeBase {
  type: 'divider';
  direction: 'horizontal' | 'vertical';
}

interface SlotNode extends NodeBase {
  type: 'slot';
  slotName: string;                    // "헤더 액션 영역"
  defaultComponentRef?: string;        // 기본으로 들어갈 MasterComponent.id
  acceptedCategories: string[];        // 교체 가능한 카테고리 제한
}

interface GroupNode extends NodeBase {
  type: 'group';
  children: ComponentNode[];           // 재귀 구조
  layout: LayoutRule;
}
```

## 5. 속성 정의

마스터 컴포넌트가 외부에 노출하는 가변 속성이다. 인스턴스에서 이 속성을 오버라이드할 수 있다.

```typescript
interface PropertyDefinition {
  name: string;                         // "title", "columns", "showPagination"
  type: PropertyType;
  defaultValue: PropertyValue;
  description: string;
}

type PropertyType =
  | { kind: 'text' }
  | { kind: 'number'; min?: number; max?: number }
  | { kind: 'boolean' }
  | { kind: 'enum'; options: string[] }
  | { kind: 'text-list' }              // string[] (컬럼명 목록 등)
  | { kind: 'component-swap' };        // 슬롯 교체용

type PropertyValue = string | number | boolean | string[];
```

## 6. 화면

```typescript
interface Screen {
  id: string;
  name: string;                        // "사용자 관리 화면"
  description: string;                 // "관리자가 사용자 목록을 조회하고 관리하는 화면"
  size: Size;                          // 화면 크기 (데스크톱 1440×900, 모바일 375×812 등)
  backgroundColor: string;

  instances: ComponentInstance[];       // 배치된 컴포넌트 인스턴스
  primitives: PrimitiveElement[];      // 독립 도형/텍스트 (컴포넌트 아닌 것)
  groups: PrimitiveGroup[];            // Detach된 독립 노드 그룹
  annotations: Annotation[];           // 기획 메모

  outgoingLinks: ScreenLink[];         // 이 화면에서 나가는 흐름
}
```

## 7. 컴포넌트 인스턴스

```typescript
interface ComponentInstance {
  id: string;
  componentRef: string;                // MasterComponent.id 참조

  position: Position;                  // 화면 위 배치 좌표
  size: Size;                          // 인스턴스 크기 (마스터 기본 크기 오버라이드 가능)

  selectedVariant: Record<string, string>;  // 배리언트 축별 선택값
  overrides: Override[];                    // 속성/스타일/가시성 오버라이드
  slotSwaps: SlotSwap[];                    // 슬롯 교체 목록

  locked: boolean;                     // 위치 고정 여부
}
```

## 8. 오버라이드

```typescript
type Override =
  | PropertyOverride
  | StyleOverride
  | VisibilityOverride
  | TextContentOverride;

interface PropertyOverride {
  type: 'property';
  propertyName: string;                // PropertyDefinition.name
  value: PropertyValue;
}

interface StyleOverride {
  type: 'style';
  targetNodePath: string;              // children 트리 내 노드 경로 (예: "header.title")
  styleKey: string;
  value: string | number;
}

interface VisibilityOverride {
  type: 'visibility';
  targetNodePath: string;
  visible: boolean;
}

interface TextContentOverride {
  type: 'text-content';
  targetNodePath: string;              // TextNode 경로
  content: string;
}
```

### 오버라이드 경로 규칙

`targetNodePath`는 children 트리를 `.`으로 구분한 경로다.

```text
"header"                    → 최상위 children 중 name이 "header"인 노드
"header.title"              → header 그룹 내 title 노드
"body.rows[0].cell[2]"     → body > rows 첫 번째 > cell 세 번째
```

## 9. 슬롯 교체

```typescript
interface SlotSwap {
  slotNodePath: string;                // SlotNode의 경로
  swappedComponentRef: string;         // 교체할 MasterComponent.id
  swappedOverrides: Override[];        // 교체된 컴포넌트에 대한 추가 오버라이드
}
```

## 10. 배리언트

```typescript
interface VariantAxis {
  name: string;             // "상태", "크기", "유형"
  values: string[];         // ["기본", "비활성", "로딩중"]
  defaultValue: string;     // "기본"
}

interface VariantSet {
  combination: Record<string, string>;  // { "상태": "로딩중", "크기": "중" }
  nodeOverrides: Override[];            // 이 조합에서 달라지는 것들
}
```

배리언트는 마스터 컴포넌트 레벨에서 정의한다. 인스턴스는 `selectedVariant`로 어떤 조합을 보여줄지 선택한다.

## 11. 독립 요소

컴포넌트가 아닌 단순 도형/텍스트는 화면에 직접 배치할 수 있다.

```typescript
type PrimitiveElement =
  | PrimitiveText
  | PrimitiveRectangle
  | PrimitiveDivider
  | PrimitiveImage;

interface PrimitiveBase {
  id: string;
  position: Position;
  size: Size;
  style: NodeStyle;
  locked: boolean;
}

interface PrimitiveText extends PrimitiveBase {
  type: 'text';
  content: string;
  textStyle: TextStyle;
}

interface PrimitiveRectangle extends PrimitiveBase {
  type: 'rectangle';
  cornerRadius: number;
  fill: FillStyle;
  stroke: StrokeStyle;
  label?: string;
}

interface PrimitiveDivider extends PrimitiveBase {
  type: 'divider';
  direction: 'horizontal' | 'vertical';
}

interface PrimitiveImage extends PrimitiveBase {
  type: 'image';
  assetRef?: string;
  placeholder: string;
}
```

## 11-1. 독립 노드 그룹

Detach된 인스턴스는 독립 노드 그룹으로 변환된다. 컴포넌트 참조 없이 자체적으로 구조를 가진다.

```typescript
interface PrimitiveGroup {
  id: string;
  name: string;                        // "목록 테이블 (분리됨)"
  position: Position;
  size: Size;
  children: PrimitiveElement[];        // 평탄화된 내부 요소
  locked: boolean;
}
```

Detach 시 인스턴스의 최종 렌더링 결과(마스터 + 배리언트 + 오버라이드 병합)를 PrimitiveElement 배열로 평탄화하여 `children`에 저장한다. 이후 마스터와의 연결은 완전히 끊어진다.

```typescript
interface Annotation {
```

## 13. 화면 흐름 링크

```typescript
interface ScreenLink {
  id: string;
  sourceScreenId: string;        // 출발 화면
  targetScreenId: string;        // 도착 화면
  triggerDescription: string;    // "목록에서 행 클릭 시"
  sourceAnchor?: Position;       // 출발 화면 내 특정 위치 (선택)
```

## 14. 공통 타입

```typescript
interface Position {
  x: number;
  y: number;
}

interface Size {
  width: number;
  height: number;
}

interface TextStyle {
  fontSize: number;
  fontWeight: 'normal' | 'bold';
  color: string;                // 시맨틱 토큰 참조
  align: 'left' | 'center' | 'right';
}

interface FillStyle {
  type: 'solid' | 'none';
  color: string;
}

interface StrokeStyle {
  width: number;
  color: string;
  style: 'solid' | 'dashed';
}

interface NodeStyle {
  opacity: number;
  rotation: number;
}

type LayoutRule =
  | { type: 'free' }                                           // 절대 위치
  | { type: 'vertical'; gap: number; padding: number }         // 세로 나열
  | { type: 'horizontal'; gap: number; padding: number }       // 가로 나열
  | { type: 'grid'; columns: number; gap: number; padding: number };  // 그리드

interface GlobalStyleSet {
  screenPresets: ScreenPreset[];     // 화면 크기 프리셋
  colorTokens: ColorToken[];        // 프로젝트 색상 토큰
  textPresets: TextPreset[];        // 텍스트 스타일 프리셋
}

interface ScreenPreset {
  name: string;           // "데스크톱", "태블릿", "모바일"
  width: number;
  height: number;
}

interface ColorToken {
  name: string;           // "primary", "secondary", "danger"
  value: string;
}

interface TextPreset {
  name: string;           // "heading-1", "body", "caption"
  style: TextStyle;
}
```

## 엔티티 수준 요약

| 엔티티 | 단위 | 공유 상태 여부 |
|---|---|---|
| ScreenSpecDocument | 문서 | 공유 |
| ComponentLibrary | 문서 내 1개 | 공유 |
| MasterComponent | 라이브러리 내 N개 | 공유 |
| ComponentNode | 마스터 내 트리 | 공유 |
| Screen | 문서 내 N개 | 공유 |
| ComponentInstance | 화면 내 N개 | 공유 |
| Override | 인스턴스 내 N개 | 공유 |
| PrimitiveElement | 화면 내 N개 | 공유 |
| PrimitiveGroup | 화면 내 N개 (Detach 결과) | 공유 |
| Annotation | 화면 내 N개 | 공유 |
| ScreenLink | 화면 내 N개 | 공유 |

모든 엔티티는 Shared Authoritative State에 포함되며, 코어의 `DocumentStore` → `SharedDocumentEngine`(Y.Doc)을 통해 관리된다.

## Y.Doc 내부 구조 매핑 방향

Y.Doc 위에 화면기획 데이터를 어떻게 저장할지는 코어 구현과 ERD 플러그인 구현 시 패턴이 확정된 후 구체화한다. 현재 예상하는 방향은 아래와 같다.

```text
Y.Doc root
├─ Y.Map("library")
│   ├─ Y.Array("categories")
│   └─ Y.Map("components")          // key: componentId → Y.Map(MasterComponent)
│       └─ Y.Array("children")      // ComponentNode 트리 (재귀)
│
├─ Y.Array("screenOrder")           // 화면 정렬 순서
├─ Y.Map("screens")                 // key: screenId → Y.Map(Screen)
│   ├─ Y.Map("instances")           // key: instanceId → Y.Map(ComponentInstance)
│   ├─ Y.Array("primitives")
│   ├─ Y.Array("groups")
│   ├─ Y.Array("annotations")
│   └─ Y.Array("outgoingLinks")
│
└─ Y.Map("globalStyles")
```

이 구조는 확정이 아니라 방향이다. ERD 플러그인의 Y.Doc 매핑 패턴이 정해지면 그 규칙을 따른다.
