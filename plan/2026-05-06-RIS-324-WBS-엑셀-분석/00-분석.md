# RIS-324 WBS 엑셀 분석

## 분석 대상
- 파일명: `함안-MM-01-01-WBS_v0.5_20260414.xlsm`
- 포맷: `application/vnd.ms-excel.sheet.macroenabled.12`
- 확인 방식:
  - 워크북 시트/셀/수식/정의된 이름/시트 숨김 여부 확인
  - `Help`, `Schedule`, `Progress`, `AnalysisReport`, `Calendar`, `Workload`, `Settings`, `TranslatedLanguages` 시트 내용 확인
  - `xl/vbaProject.bin` 존재 확인으로 매크로 기반 워크북임을 검증

## 신뢰도 기준
- `직접 확인`: 셀 구조, 수식, 시트명, 숨김 상태, 설정값, 정의된 이름 등 워크북 내부에서 직접 확인한 내용
- `시트 내 명시`: `Help` 또는 번역/설정 시트가 기능으로 명시하고 있는 내용
- `추론`: 직접 확인한 구조를 바탕으로 높은 확률로 동작한다고 판단되는 내용

## 워크북 개요
- `직접 확인`: 시트 구성은 `Help`, `Schedule`, `Progress`, `AnalysisReport`, `Calendar`, `TranslatedLanguages`, `Workload`, `Settings` 총 8개다.
- `직접 확인`: `TranslatedLanguages`, `Settings`는 숨김 시트다.
- `직접 확인`: `Settings` 시트의 `PROGRAM_NAME=XLGantt`, `VERSION=6.0.0`, `PROGRAM_SITE=https://xlworks.net/en/xlgantt-project-scheduler/` 값으로 보아 XLGantt 기반 템플릿이다.
- `직접 확인`: `Schedule` 시트는 `A5` 기준으로 freeze pane이 걸려 있고, `AF:AT` 구간에 주차 기반 타임라인 헤더가 배치되어 있다.

## Schedule 시트에서 직접 확인되는 기능

### 1. 계층형 WBS 작성
- `직접 확인`: 컬럼 `C=wbs_level`, `D=WBS`가 존재한다.
- `직접 확인`: 실제 작업명 입력 영역이 `E:N`에 계층적으로 배치되어 있고, 레벨이 깊어질수록 오른쪽 컬럼에 작업명이 들어간다.
- `직접 확인`: 예시 데이터에서 최대 7레벨 이상의 WBS 코드가 존재한다. `2.2.1.5.2.3.1` 같은 하위 구조가 보인다.
- `추론`: 단일 작업명 컬럼이 아니라 레벨별 들여쓰기 구조를 시트 레이아웃 자체로 표현하는 방식이다.

### 2. 그룹 작업과 말단 작업의 구분
- `직접 확인`: `B=task_group` 컬럼에 `G` 값이 들어간 행이 존재한다.
- `직접 확인`: 그룹 행은 담당자/실제일자 없이 하위 작업들의 일정과 작업량을 집계한 값처럼 나타난다.
- `추론`: 그룹 행과 leaf 작업 행을 분리하여 상위 WBS는 roll-up, 하위 작업은 실제 입력 대상으로 쓰는 구조다.

### 3. 계획 일정과 실제 일정의 이중 관리
- `직접 확인`: 계획 컬럼으로 `P=시작일`, `Q=완료일`, `T=계획작업량`, `V=계획기간`, `AD=계획진척률`이 있다.
- `직접 확인`: 실제 컬럼으로 `W=실제시작일`, `X=실제완료일`, `Y=실제총작업량`, `Z=실제총기간`, `AE=실적진척률`이 있다.
- `직접 확인`: 일부 완료 작업은 `W/X/Y/Z` 값이 채워져 있고 미완료 작업은 비어 있다.
- `추론`: 계획 기준과 실제 기준을 분리해 일정변경 관리 또는 실적 추적을 수행하도록 설계되어 있다.

### 4. 작업량과 기간 자동 계산
- `직접 확인`: `S=총작업량`, `T=계획작업량`, `U=총기간`, `V=계획기간`, `Y=실제총작업량`, `Z=실제총기간`, `AA=자원수` 컬럼이 있다.
- `직접 확인`: `Progress` 시트 설명에 "프로젝트 전체 작업량", "현재일까지 계획된 작업량", "실적기성", "실제 투입된 작업량"이 표시된다.
- `직접 확인`: `Settings`에 `optWorkloadCalcByResourceAssignRate=1`, `txtAvgWorkingdays=20` 같은 옵션이 있다.
- `추론`: 휴무일과 자원수를 반영해 Man-Day 기준 작업량/기간을 자동 계산하는 구조다.

### 5. 계획 진척률과 실적 진척률 자동 계산
- `직접 확인`: `AD=계획`, `AE=실적*` 컬럼이 존재한다.
- `직접 확인`: `Progress` 시트의 정의된 이름 `PLANNED_RATE`, `ACTUAL_RATE`, `RATE_GAP`가 각각 `Progress!B18`, `B21`, `B24`를 참조한다.
- `직접 확인`: `Progress` 시트 설명에 `"스케줄업데이트" 버튼 클릭 시 아래 항목이 자동계산됩니다.` 문구가 있다.
- `직접 확인`: `B24`는 `=ACTUAL_RATE-PLANNED_RATE` 수식이다.
- `추론`: 각 작업의 실적 입력을 기반으로 계획 대비 실적 편차를 프로젝트 수준까지 집계하는 구조다.

### 6. 주차 단위 간트/타임라인 표시
- `직접 확인`: `AF:AT` 구간에 `04/12 W16`, `05/10 W20`, `06/07 W24`, `07/05 W28` 같은 주차 헤더가 있고, 하단에는 주 시작일이 있다.
- `직접 확인`: `AF5`, `AG19`, `AH35` 등 셀에는 `"실적진척률 + 작업명 + 담당 + 기간"`을 조합한 문자열 수식이 들어 있다.
- `직접 확인`: `Schedule` 시트에는 `ConditionalFormatting D5:AD310` 규칙이 있다.
- `추론`: 주차별 막대 또는 텍스트 기반 간트 표시를 위해 작업 라벨과 진척률/기간을 조합해 시각화하는 구조다.

### 7. 담당자와 산출물 연결
- `직접 확인`: `AB=담당`, `AC=산출물` 컬럼이 존재한다.
- `직접 확인`: `Workload` 시트에 `resource` 컬럼이 있고 각 leaf task가 담당자와 함께 풀려 있다.
- `직접 확인`: `Help` 시트에 산출물 저장 경로 지정 및 `Schedule` 시트에서 바로 산출물을 열 수 있다는 설명이 있다.
- `추론`: 작업별 책임자 배정과 산출물 링크/경로 관리가 엮여 있다.

### 8. 프로젝트 기준일/범위 제어
- `직접 확인`: `Settings`에 `projectStartDate`, `projectEndDate`, `optPlanRateCriteriaDate`, `setTaskDateToProjectDate` 값이 있다.
- `추론`: 프로젝트 기준일을 바꾸면 계획 진척률 산정 기준과 간트 범위가 함께 재계산되는 구조다.

## 보조 시트에서 직접 확인되는 기능

### 1. 프로젝트 전체 진척률 대시보드
- `직접 확인`: `Progress` 시트가 프로젝트 전체 작업량, 계획 작업량, 실적기성, 계획 진척률, 실적 진척률, 차이값을 보여준다.
- `직접 확인`: 정의된 이름 `TOTAL_WORKLOAD`, `PLANNED_WORKLOAD`, `ACTUAL_WORKLOAD`, `ACTUAL_WORKLOAD2`, `PLANNED_RATE`, `ACTUAL_RATE`, `RATE_GAP`가 연결돼 있다.

### 2. 주간 누적 진척 분석
- `직접 확인`: `AnalysisReport` 시트는 주차별 `시작일`, `완료일`, `계획작업량`, `계획작업량 누적`, `계획작업량 진척률`, `실적기성`, `실적기성 누적`, `실제작업량`, `실제작업량 누적` 컬럼을 가진다.
- `직접 확인`: 누적 수식(`=E7+D8`, `=H7`, `=SUM(D7:D21)` 등)이 들어 있다.
- `추론`: 주간 cadence로 계획 누적선과 실제 누적선을 비교하는 리포트 기능이 있다.

### 3. 휴무일/캘린더 관리
- `직접 확인`: `Calendar` 시트는 `표준캘린더`, `사용자정의 캘린더1`, `사용자정의 캘린더2` 3개 영역을 가진다.
- `직접 확인`: 정의된 이름 `STD_CAL`, `UD_CAL1`, `UD_CAL2`가 각각 캘린더 범위를 참조한다.
- `직접 확인`: 공휴일명과 날짜를 입력하면 옆 셀에서 `TEXT(date,"(aaa)")` 수식으로 요일이 자동 표시된다.
- `추론`: 프로젝트별 비근무일 예외를 표준/사용자 정의 세트로 나눠 관리하고 일정 계산에 반영한다.

### 4. 리소스별 Workload 원본 데이터 생성
- `직접 확인`: `Workload` 시트는 `wbsLevel`, `wbs`, `wbsLevel01~10`, `task`, `resource` 등 정규화된 컬럼을 가진다.
- `직접 확인`: 동일 task가 여러 행으로 반복되는 구간이 있어 주별/월별 배분 또는 pivot용 raw data 성격이 강하다.
- `직접 확인`: `Help` 시트에 `Workload data를 주별/월별로 만들어 주며 pivot 등의 기능으로 분석할 수 있다`고 명시돼 있다.
- `추론`: 리소스 부하 분석, 피벗 분석, 인력별 월/주 투입량 리포트 생성을 위한 데이터셋이다.

### 5. 다국어 UI/문구 사전
- `직접 확인`: `TranslatedLanguages` 숨김 시트에 `English`, `Korean`, `Custom` 컬럼이 있다.
- `직접 확인`: `Settings`에 `languageSelectedByManual` 값이 있다.
- `추론`: UI 문구와 도움말을 테이블 기반으로 교체하는 다국어 구조다.

## Help/Settings 시트에 명시된 기능
- `시트 내 명시`: 작업명, 시작일, 완료일, 진척률 입력 시 휴무일/자원수를 고려해 `작업기간`, `계획진척률`, `실적진척률`, `작업량`을 자동 계산한다.
- `시트 내 명시`: `일정계획 변경관리` 기능으로 실제 시작일/실제 완료일을 입력할 수 있다.
- `시트 내 명시`: 간트차트 표시 옵션, WBS 영역, 컬러 테마 설정 기능이 있다.
- `시트 내 명시`: 작업 의존관계 `FS`, `SS`, `FF`, `SF`를 설정할 수 있다.
- `시트 내 명시`: 산출물 저장 경로를 지정하고 `Schedule` 시트에서 바로 열 수 있다.
- `시트 내 명시`: Microsoft Outlook 작업/일정 등록 기능이 있다.
- `시트 내 명시`: 다른 XLGantt 파일 또는 일반 Excel 파일에서 일정 가져오기 기능이 있다.
- `시트 내 명시`: 프로젝트의 휴무일 설정, 주 시작요일 지정, 주차 표시 기능이 있다.
- `시트 내 명시`: 분석 리포트와 Workload 리포트 생성 기능이 있다.

## 순수 엑셀 내용만 보고 정리한 기능 리스트
1. 다단계 WBS 계층 작성 및 상하위 그룹 구조 관리
2. 그룹 작업과 개별 작업을 분리한 roll-up 일정/작업량 집계
3. 계획 시작일/완료일 관리
4. 실제 시작일/완료일 관리
5. 계획 작업량(Man-Day) 계산
6. 실제 작업량 및 실제 투입기간 계산
7. 자원수 기반 작업량 보정
8. 작업 담당자 지정
9. 산출물 연결 또는 산출물 경로 관리
10. 작업별 계획 진척률 자동 산정
11. 작업별 실적 진척률 입력 및 집계
12. 프로젝트 전체 계획/실적 진척률 요약
13. 계획 대비 실적 편차 계산
14. 주차 단위 간트/타임라인 시각화
15. 주간 누적 진척 분석 리포트
16. 리소스별 workload 원본 데이터 생성
17. 공휴일/휴무일 반영 캘린더 계산
18. 표준 캘린더와 사용자 정의 캘린더 분리
19. 프로젝트 시작일/종료일 및 기준일 설정
20. 다국어 문구 테이블 기반 UI 전환
21. 일정변경 관리 옵션 기반 실적 추적
22. 간트 표시 옵션, 컬러 테마, 줌, 그룹 표시 같은 화면 설정 저장
23. 의존관계(FS/SS/FF/SF) 설정
24. Outlook 일정/작업 연동
25. 외부 Excel/XLGantt 일정 가져오기

## 유의사항
- 이 문서는 `우리 제품과의 비교`가 아니라 첨부된 엑셀 파일 내부에서 확인되거나 강하게 추론되는 기능만 정리했다.
- `의존관계`, `Outlook`, `가져오기`처럼 실제 동작 UI를 직접 실행하지 못한 항목은 `Help` 시트 명시를 근거로 포함했다.
- VBA 모듈 본문까지 완전 복호화하지는 않았지만, `xl/vbaProject.bin`이 포함되어 있어 매크로 구동 워크북이라는 점은 확인했다.
