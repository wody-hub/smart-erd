## Tasks

1. Add `WbsCommentAddActionExecutor` for `wbs.comment.add` using `WorkItemHistoryService.addWbsComment(...)`.
2. Add `WbsMemoAddActionExecutor` for `wbs.memo.add` using the same service boundary, with action-specific result summary.
3. Require nonblank `content` and existing WBS target id.
4. Update proposal service tests so the six Phase 12 action types are executable when registered, while unknown/destructive types still reject without mutation.
5. Add non-mutation tests for blank content, wrong target type, missing target id, target-not-found/access-denied service exceptions, and destructive-looking action types.

## Acceptance Criteria

- Approved WBS comment/memo proposals create exactly one WBS comment through the history service.
- Invalid WBS proposals do not create comments.
- Delete/bulk/shell/sql action types remain unsupported or invalid before executor mutation.
