## 3. 상세 명세

### 3-1. DocumentHubTabContent (추출)

**DiagramsPage에서 이동할 코드:**
- `useQuery(diagrams)`, `useQuery(dictionarySets)`
- `useDiagramDocumentHubActions` 훅
- `documentItems` useMemo
- surface-operational 밴드 (DocumentTypeBadge + 카운트)
- 로딩/에러/빈 상태 분기 + 문서 목록
- `CreateDocumentDialog`, `ConfirmDialog`

**Props:**
```typescript
interface DocumentHubTabContentProps {
  teamId: string;
  projectId: string;
  canEdit: boolean;
  openTrigger: number;  // 카운터 패턴 — 부모에서 다이얼로그 열기 트리거
}
```

- `openTrigger`: `useEffect(() => { if (openTrigger === 0) return; setDialogOpen(true); }, [openTrigger])`
- 다이얼로그 상태(`dialogOpen`)는 내부 소유

### 3-2. BusinessOverviewTab

**Props:**
```typescript
interface BusinessOverviewTabProps {
  teamId: string;
  projectId: string;
  canEdit: boolean;
  documentCount: number;  // 요약 카드 표시용
}
```

**코드 순서** (Page Component Code Ordering 준수):
```
1  useQueryClient
2  useTranslation → t, i18n
3  useState: isEditing
4  useState: form (BusinessOverviewFormState)
5  useQuery: fetchBusinessOverview
6  useMutation: updateBusinessOverview (PATCH)
7  핸들러: handleEditStart, handleCancel, handleSave
8  useEffect: isEditing → form 초기화
9  조건부 리턴: isLoading → Spinner
10 JSX
```

**JSX 구조:**
```
<div className="space-y-6">
  ┌─ 제목 + 편집 버튼 (canEdit && !isEditing)
  ├─ [빈 상태] WorkspaceEmptyState (isDataEmpty && !isEditing)
  ├─ [요약 카드 3장] grid cols-3 (memberCount, documentCount, progressRate)
  ├─ [읽기 모드] <dl> grid cols-2 — 6개 필드
  ├─ [편집 모드] <form> grid cols-2 — Label+Input 6개 필드
  └─ [편집 액션] 취소/저장 버튼
</div>
```

**읽기 모드:**
- `<dl>` 시맨틱 마크업, `grid grid-cols-1 md:grid-cols-2 gap-6`
- `projectScope`는 `col-span-full`, `whitespace-pre-wrap`
- 금액: `formatCurrency(data.contractAmount)` + `"원"`
- 날짜: `formatProjectDate(data.projectStartDate, i18n.language)`
- null 필드: `t('businessOverview.field.empty')` ("미등록")

**편집 모드:**

| 필드 | 입력 컴포넌트 | 특이사항 |
|---|---|---|
| clientCompany | `<Input>` | 텍스트, max 200 |
| contractorCompany | `<Input>` | 텍스트, max 200 |
| contractAmount | `<Input type="text" inputMode="numeric">` | 숫자 입력 |
| projectStartDate | `<Input type="date">` | native date picker |
| projectEndDate | `<Input type="date">` | native date picker |
| projectScope | `<Textarea rows={4}>` | col-span-full, resize-none |

각 필드: `<Label htmlFor={id}>` + `<Input id={id}>` (a11y).

**요약 카드** — 파일 내 로컬 서브컴포넌트:
```typescript
function SummaryCard({ label, value, unit }: { label: string; value: string | number; unit?: string }) {
  return (
    <div role="group" className="rounded-xl border border-border bg-card p-4" aria-label={label}>
      <p className="text-sm text-muted-foreground">{label}</p>
      <p className="mt-1 text-2xl font-semibold text-foreground">
        {value}
        {unit && <span className="ml-1 text-sm font-normal text-muted-foreground">{unit}</span>}
      </p>
    </div>
  );
}
```

**isDataEmpty 파생값:**
```typescript
const isDataEmpty = !data || (
  data.clientCompany == null && data.contractorCompany == null &&
  data.contractAmount == null && data.projectStartDate == null &&
  data.projectEndDate == null && data.projectScope == null
);
```

**handleSave 흐름:**
1. `isDateOrderValid(form.startDate, form.endDate)` → 실패 시 `toast.error`
2. `saveMutation.mutate(payload)` — `Partial<BusinessOverview>` 변환
3. onSuccess: `invalidateQueries(businessOverview)` + `setIsEditing(false)` + `toast.success`
4. onError: `toast.error(getErrorMessage(err, t('businessOverview.save.failed')))`

**편집 폼 초기화:**
```typescript
useEffect(() => {
  if (!isEditing || !data) return;
  setForm({
    clientCompany: data.clientCompany ?? '',
    contractorCompany: data.contractorCompany ?? '',
    contractAmountRaw: data.contractAmount != null ? String(data.contractAmount) : '',
    startDate: data.projectStartDate ?? '',
    endDate: data.projectEndDate ?? '',
    projectScope: data.projectScope ?? '',
  });
}, [isEditing, data]);
```

### 3-3. DiagramsPage 탭 셸 재구성

**DiagramsPage에 남길 부분:**
- `useParams`, `useNavigate`, `useQueryClient`, `useTranslation`
- `useState<'documents' | 'overview'>`: activeTab (기본값: 'documents')
- `useQuery(team)`, `useQuery(project)`, `useTeamRole`
- `useQuery(diagrams)` — documentCount 파생용 (캐시 공유로 중복 요청 없음)
- Header, Back 버튼, ProjectWorkspaceHero
- Tabs 셸

**히어로 분기:**
- `activeTab === 'documents'`: primaryAction = 문서 생성 버튼, utilityActions 유지
- `activeTab === 'overview'`: primaryAction = undefined, utilityActions = undefined

**Tabs 구조:**
```tsx
<Tabs value={activeTab} onValueChange={setActiveTab} className="mt-6">
  <TabsList>
    <TabsTrigger value="documents">
      <FileText className="mr-2 h-4 w-4" />
      {t('businessOverview.documentsTab')}
    </TabsTrigger>
    <TabsTrigger value="overview">
      <ClipboardList className="mr-2 h-4 w-4" />
      {t('businessOverview.tab.title')}
    </TabsTrigger>
  </TabsList>

  <TabsContent value="documents">
    <DocumentHubTabContent ... />
  </TabsContent>
  <TabsContent value="overview">
    <BusinessOverviewTab ... documentCount={diagrams.length} />
  </TabsContent>
</Tabs>
```

**TabsList 위치:** ProjectWorkspaceHero 직하, surface-operational 밴드는 DocumentHubTabContent 내부로 이동.

## 5. 상태 흐름

```
[초기 진입] activeTab='documents'
  → diagrams/team/project 쿼리 발화
  → BusinessOverview 쿼리 미발화

[탭 전환 → overview]
  → BusinessOverviewTab 마운트 → useQuery 발화
  → 미등록: WorkspaceEmptyState 렌더링
  → 등록됨: ReadView 렌더링

[편집 진입] handleEditStart → setIsEditing(true) → useEffect → form 초기화

[저장] handleSave → 날짜 검증 → mutate → onSuccess: invalidate + setIsEditing(false)

[취소] handleCancel → setIsEditing(false) (form은 다음 편집 시 재초기화)
```
