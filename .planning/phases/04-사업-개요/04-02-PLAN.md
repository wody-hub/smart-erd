## 3. 상세 명세

### 3-1. `types/project.ts` — 인터페이스 추가

기존 `Project` 인터페이스 아래에 추가:

```typescript
/** 사업 개요 — 프로젝트별 계약/일정/범위 정보. 모든 필드 nullable (초기 미입력 상태). */
export interface BusinessOverview {
  /** 발주사명 */
  clientCompany: string | null;
  /** 수주사명 */
  contractorCompany: string | null;
  /** 계약 금액 (원화 단위 정수) */
  contractAmount: number | null;
  /** 프로젝트 시작일 (ISO 8601: "2026-01-01") */
  projectStartDate: string | null;
  /** 프로젝트 종료일 */
  projectEndDate: string | null;
  /** 프로젝트 범위/목적 기술 */
  projectScope: string | null;
}

/** 프로젝트 요약 지표 — 사업 개요 탭 상단 요약 카드용 */
export interface ProjectSummary {
  /** 팀 참여 인원 수 */
  memberCount: number;
  /** 프로젝트 문서 총 수 */
  documentCount: number;
  /** 진행률 (0~100, null이면 미집계) */
  progressRate: number | null;
}
```

**필드명 규칙:** BE 응답 필드명과 1:1 대응 (`clientCompany`, `contractorCompany`, `projectStartDate`, `projectEndDate`).

### 3-2. `lib/format.ts` — 신규 생성

React 의존성 없는 순수 유틸:

```typescript
/** 숫자를 한국 원화 표기로 포맷 ("150,000,000원") */
export function formatCurrency(amount: number): string {
  return `${amount.toLocaleString('ko-KR')}원`;
}

/** ISO 8601 날짜를 locale 기준으로 포맷 (ko: "2026년 1월 1일") */
export function formatProjectDate(date: string, locale: string): string {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric', month: 'long', day: 'numeric',
  }).format(new Date(date));
}
```

- `formatCurrency`: `'ko-KR'` 고정 — 금액 단위는 항상 원화
- `formatProjectDate`: `locale` 파라미터 수신 — `i18n.language` 주입

### 3-4. `api/projectApi.ts` — 함수 2개 추가

```typescript
import type { BusinessOverview } from '@/types/project';

/** 사업 개요 조회 */
export async function fetchBusinessOverview(
  teamId: string, projectId: string
): Promise<BusinessOverview> {
  const res = await axiosInstance.get<BusinessOverview>(
    `/teams/${teamId}/projects/${projectId}/business-overview`
  );
  return res.data;
}

/** 사업 개요 수정 (PATCH) */
export async function updateBusinessOverview(
  teamId: string, projectId: string, data: Partial<BusinessOverview>
): Promise<BusinessOverview> {
  const res = await axiosInstance.patch<BusinessOverview>(
    `/teams/${teamId}/projects/${projectId}/business-overview`, data
  );
  return res.data;
}
```

- HTTP 메서드: **PATCH** (BE와 일치)
- `Partial<BusinessOverview>`: 부분 업데이트 유연성

## 4. 데이터 흐름

```
BusinessOverviewTab (Phase 04-03)
  │
  ├─ useQuery({
  │    queryKey: queryKeys.projects.businessOverview(teamId, projectId),
  │    queryFn: () => fetchBusinessOverview(teamId, projectId),
  │  })
  │
  ├─ useMutation({
  │    mutationFn: (data) => updateBusinessOverview(teamId, projectId, data),
  │    onSuccess: invalidateQueries + toast.success,
  │    onError: toast.error(getErrorMessage),
  │  })
  │
  └─ 렌더링
       ├─ formatCurrency(data.contractAmount)
       └─ formatProjectDate(data.projectStartDate, i18n.language)
```
