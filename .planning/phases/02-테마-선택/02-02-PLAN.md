다음 exact target state로 구현한다.

1. `DESIGN.md`에 Paper / Graphite / Midnight 3-theme 구조를 명시한다.
   - Paper: 현재 warm editorial direction 유지
   - Graphite: cool gray/slate dark theme, accent `#5B8DEF`, background `#272C33`
   - Midnight: current dark shell 계열 유지
   - Monaco mapping은 `paper => vs`, `graphite => vs-dark`, `midnight => vs-dark`로 명시한다

2. `client/src/index.css`의 token selector 구조를 아래로 바꾼다.
   - `:root, .theme-paper { ...Paper tokens... }`
   - `.theme-graphite { ...Graphite tokens... }`
   - `.theme-midnight { ...Midnight tokens... }`
   - 기존 `.dark { ... }` 블록은 authoritative selector로 남겨두지 않는다

3. Graphite token set은 `02-UI-SPEC.md` 값을 그대로 사용한다. 최소한 아래 값들은 exact match로 반영한다.
   - `--background: 220 14% 18%`
   - `--card: 220 14% 22%`
   - `--primary: 220 80% 62%`
   - `--foreground: 220 15% 94%`
   - `--muted-foreground: 220 8% 62%`
   - `--border: 220 10% 30%`
   - `--header-bg: 220 16% 14%`
   - `--erd-table-header: 220 80% 62%`
   - `--erd-table-supporting: 168 54% 42%`
   - `--erd-table-attention: 38 58% 54%`

4. Midnight token set은 현재 `.dark` 값을 `.theme-midnight`로 이전한다.
   - 값 자체를 새로 디자인하지 말고 현재 dark token을 유지한다

5. Body background gradient도 theme class를 따라가도록 유지한다.
   - Paper는 현재 warm gradient 유지
   - Graphite는 UI-SPEC의 graphite gradient 공식을 적용한다
   - Midnight는 현재 dark gradient를 유지한다

6. 새 raw hex hard-code를 컴포넌트 레벨에 추가하지 않는다.
   - theme 전개는 `index.css` variable layer에서 끝내고, 기존 Tailwind semantic mapping을 그대로 사용한다
