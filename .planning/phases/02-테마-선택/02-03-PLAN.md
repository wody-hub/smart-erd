1. `client/src/components/layout/ThemeSwitcher.tsx`를 새로 만든다.
   - `Palette` 아이콘 버튼을 사용한다
   - `DropdownMenuLabel`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`을 포함한 `DropdownMenu`를 사용한다
   - 항목은 정확히 `Paper`, `Graphite`, `Midnight` 3개다
   - 각 항목 왼쪽에 12px 원형 swatch를 둔다

     - Graphite swatch: `#272C33`
     - Midnight swatch: `#0A1020`
   - 메뉴 상단에 `t('theme.current')` label을 둔다
   - 현재 선택된 항목에는 radio semantics + existing `DropdownMenuRadioItem` indicator + 강조 스타일을 함께 준다
   - shared `client/src/components/ui/dropdown-menu.tsx` primitive는 수정하지 않는다
   - 클릭 시 `useThemeStore().setTheme(theme)`를 호출한다
   - 버튼 `aria-label`은 `t('theme.aria.switchTheme')`를 사용한다

2. `Header.tsx`의 `header-utility-group`에서 `LanguageSwitcher` 왼쪽에 `ThemeSwitcher`를 넣는다.
