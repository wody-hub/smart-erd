## Theme Architecture

### Strategy

3 curated themes implemented as CSS class selectors on `document.documentElement`:

| Theme | Class | Tone | Monaco Mapping |
|-------|-------|------|----------------|
| Paper | `.theme-paper` (default, no class also works) | Warm cream/ivory | `vs` |
| Graphite | `.theme-graphite` | Cool gray/slate | `vs-dark` |
| Midnight | `.theme-midnight` | Deep navy/cobalt | `vs-dark` |

### CSS Variable Override Hierarchy

```
:root                       -- Paper 기본값 (현재 :root 유지)
.theme-paper                -- :root와 동일 (명시적 선언)
.theme-graphite             -- 서늘한 그레이 독립 토큰셋
.theme-midnight             -- 네이비 다크 독립 토큰셋 (현재 .dark 기반)
```

### Dark Mode Hook Migration

현재 `useDarkMode()` 훅은 `.dark` 클래스를 감시한다. 테마 시스템 도입 후:
- `useDarkMode()` -> `useThemeStore()` 의 `isDark` 파생값으로 대체
- `isDark` = `theme === 'graphite' || theme === 'midnight'`
- Monaco, React Flow 등 외부 라이브러리의 `isDark` 분기는 이 파생값 사용

### Midnight (Deep Navy) -- 현재 `.dark` 값 기반

현재 `index.css`의 `.dark` 선택자에 정의된 모든 토큰을 `.theme-midnight`로 이전한다. 변경사항 없이 그대로 사용하되 선택자만 변경:

- 기존: `.dark { --background: 223.6 52.4% 8.2%; ... }`
- 변경: `.theme-midnight { --background: 223.6 52.4% 8.2%; ... }`

모든 값은 현재 `.dark` 블록의 값과 동일.

### Accent Reserved For (모든 테마 공통)

Primary accent (10%)는 다음 요소에만 사용:
- Primary CTA 버튼 (`bg-primary`)
- 활성 탭/네비게이션 인디케이터
- 포커스 링 (`ring`)
- 링크 텍스트
- ERD 테이블 헤더 기본색
- FK 마커
- 협업 연결 중 상태

## Body Background Gradient

각 테마의 `body` 배경 그라디언트:

**Paper:** 현재 `index.css`의 body 배경 유지 (warm radial gradients)

**Graphite:**
```css
background-image:
  radial-gradient(circle at top left, hsl(var(--brand-secondary) / 0.05), transparent 22%),
  radial-gradient(circle at top right, hsl(var(--primary) / 0.05), transparent 28%),
  linear-gradient(
    180deg,
    hsl(var(--background)) 0%,
    hsl(var(--background)) 64%,
    hsl(var(--secondary) / 0.72) 100%
  );
```

**Midnight:** 현재 `.dark` body와 동일한 그라디언트 (opacity 값 동일)

## Theme Switcher Component

### 위치
Header.tsx > `.header-utility-group` 내부, `LanguageSwitcher` 왼쪽

### 구현
- 아이콘 버튼: `Palette` (lucide-react) 또는 `Sun`/`Moon`/`Monitor` 3개 대신 단일 `Palette` 아이콘
- 클릭 시 shadcn DropdownMenu 표시
- 드롭다운 아이템 3개: Paper / Graphite / Midnight
- 현재 선택된 테마에 `font-bold` + 체크마크 아이콘 표시
- `aria-label`: `t('theme.aria.switchTheme')`

### 드롭다운 아이템 레이아웃

```
[o] Paper         -- 원형 색상 스와치 + 텍스트 + 체크(선택됨)
[ ] Graphite
[ ] Midnight
```

색상 스와치: 12px 원형, 각 테마의 `--background` 색상 표시
- Paper 스와치: `#F6F1E8`
- Graphite 스와치: `#272C33`
- Midnight 스와치: `#0A1020`

## Theme Store (Zustand)

### 파일: `client/src/stores/useThemeStore.ts`

```typescript
type Theme = 'paper' | 'graphite' | 'midnight';

interface ThemeState {
  theme: Theme;
  isDark: boolean;           // 파생값: graphite | midnight
  setTheme: (t: Theme) => void;
}
```

### localStorage 키
`STORAGE_KEYS.THEME` = `'smart-erd-theme'`

### 초기화 동작
1. `localStorage.getItem(STORAGE_KEYS.THEME)` 읽기
2. 유효한 값이면 사용, 없거나 잘못된 값이면 `'paper'` 기본값
3. `document.documentElement.className`에서 기존 테마 클래스 제거 후 새 클래스 추가
4. Graphite/Midnight이면 `document.documentElement.classList.add('dark')` (Tailwind dark mode 호환)

### Class 토글 규칙
- Paper: `.theme-paper` (`.dark` 없음)
- Graphite: `.theme-graphite .dark`
- Midnight: `.theme-midnight .dark`

`.dark` 클래스를 함께 추가하는 이유: 기존 `useDarkMode()` 훅과 Tailwind `dark:` 접두사 호환성 유지. 점진 마이그레이션 가능.

## CSS 구현 가이드

### index.css 구조

```css
@layer base {
  :root,
  .theme-paper {
    /* 현재 :root 값 그대로 */
  }

  .theme-graphite {
    /* Graphite 토큰셋 (이 문서의 Graphite 테이블) */
  }

  .theme-midnight {
    /* 현재 .dark 값을 이동 */
  }
}
```

### tailwind.config.js 변경

`darkMode: ["class"]` 유지. Tailwind의 `dark:` 접두사는 `.dark` 클래스에 반응하므로, Graphite와 Midnight 모두 `.dark` 클래스를 함께 추가하여 호환성 유지.

추가 변경: 없음. 기존 `tailwind.config.js` 색상 매핑은 CSS Variable을 참조하므로 테마 전환 시 자동 반영.

### 기존 `.dark` 셀렉터 마이그레이션

`.dark` 셀렉터의 CSS Variable 정의를 `.theme-midnight`로 이동한다. `.dark` 셀렉터 자체는 빈 상태로 유지하거나 제거한다. Tailwind `dark:` 유틸리티 클래스가 코드베이스에서 사용되는 경우, `.dark` 클래스가 `<html>`에 여전히 추가되므로 기존 `dark:` 접두사도 정상 동작한다.
