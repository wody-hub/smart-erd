## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend response to visible UI | Structured answer data becomes user-facing content. |
| Context selector to send lifecycle | User-selected scope is a hint sent to backend, not authorization. |
| Runtime error to UI | Backend/provider failures are displayed without raw diagnostic leakage. |
