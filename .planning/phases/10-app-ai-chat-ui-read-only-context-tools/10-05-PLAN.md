## Source Audit

This plan covers GOAL chat send/receive plumbing, REQ AI-CHAT-01 and AI-CHAT-02, RESEARCH/API-module constraints, UI-SPEC API and state contract, and CONTEXT decisions D-28 and D-29. It does not implement provider runtime, Electron IPC, server history, or write/action UI.

## Must Haves

- `aiChatApi` is the only frontend module that calls `/api/ai/chat`.
- Components and hooks do not call `axiosInstance` directly except inside `client/src/api/aiChatApi.ts`.
- Send stores the request message with send-time context and stores the rendered response sections, not raw backend/provider payloads.
- Cancel uses the Phase 9 cancel endpoint via existing API module or a typed wrapper and never clears the transcript.
