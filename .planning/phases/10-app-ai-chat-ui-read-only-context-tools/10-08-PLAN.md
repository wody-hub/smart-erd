## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI read services -> provider context | Sanitized Smart-ERD project summaries become provider-readable prompt context. |
| authenticated user -> provider gateway | Login identity authorizes and owns execution records but must not enter provider prompt context. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-10-08-02 | Information Disclosure | `AiExecutionGateway.sanitizedContext` | mitigate | Remove `loginId` from `RunCommand.providerContext`; keep identity only in runner login argument for registry/audit ownership. |
| T-10-08-03 | Tampering | `AiChatExecutionService` provider request assembly | mitigate | Regression-test the exact `RunCommand.providerContext().get("readContext")` payload shape so provider grounding cannot silently regress to generic facts. |
| T-10-08-SC | Tampering | package-manager installs | accept | No npm, pip, cargo, or Gradle dependency install is planned. |
