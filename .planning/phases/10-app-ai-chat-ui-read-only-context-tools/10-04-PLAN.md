## Source Audit

This plan covers GOAL truths for user-facing chat state and context display, REQ AI-CHAT-01 and AI-CHAT-02, RESEARCH guidance for Zustand/localStorage and client-only route hints, UI-SPEC local persistence rules, and CONTEXT decisions D-01 through D-13 plus D-29. It applies the resolved local retention decision: store only the most recent 50 rendered messages per authenticated login/user storage key, with no TTL. It does not assemble project data in the browser per D-27 and D-28.

## Must Haves

- Store key includes authenticated login/user identifier to prevent cross-user browser-local bleed.
- Store state persists drawer open state, selected context, backend confirmation candidates, and rendered messages only.
- Store truncates rendered messages to the most recent 50 per authenticated login/user storage key; no TTL is introduced in Phase 10.
- `newConversation()` is the only in-app conversation reset; logout clearing prevents cross-user bleed.
- `useAiRouteContext` identifies strong team/project context, team-only context, and weak screens.
