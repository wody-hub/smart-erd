## Source Audit

This plan covers GOAL truths for authorized project-data grounding, REQ AI-CHAT-02 and AI-READ-01 through AI-READ-04, RESEARCH responsibilities for API/backend-owned context disambiguation and summary-first reads, and CONTEXT decisions D-07 through D-22 plus D-27. ## Must Haves

- Scope input is treated as untrusted and revalidated on the server.
- Multi-project expansion is limited to accessible projects in the current team per D-10 and excludes all-team querying per D-11.
- Ambiguous/misspelled/conflicting project names produce confirmation candidates before provider execution per D-12 and D-26.
- TODO reads default to current-user TODOs; member-wide TODO is summary-only and only when explicitly asked and authorized per D-19 through D-21.
