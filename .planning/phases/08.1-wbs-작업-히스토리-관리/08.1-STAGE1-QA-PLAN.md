# 08.1 Stage 1 QA Plan (RIS-250)

## Scope

- 대상: `WBS 문서 연결 + Tags 탭 MVP`
- 의존 이슈:
  - [RIS-248](/RIS/issues/RIS-248) (백엔드)
  - [RIS-249](/RIS/issues/RIS-249) (프런트)

## Entry Criteria (QA 시작 조건)

- `RIS-248`, `RIS-249`가 모두 `done` 또는 QA 요청 코멘트와 함께 `in_review` 상태다.
- API/UI 계약이 코멘트 또는 문서로 고정되어 있다.
- 기본 회귀 테스트(문서 허브/WBS 편집) 실행 방법이 공유되어 있다.

## Test Matrix

1. WBS 문서 연결
- WBS 상세에서 새 문서를 생성하고 해당 WBS에 연결된다.
- WBS 상세에서 기존 문서를 연결/해제할 수 있다.
- 연결 상태가 새로고침 후에도 유지된다.

2. Tags 탭 조회
- 태그 목록이 프로젝트 문서 메타데이터와 일치한다.
- 태그 선택 시 태그별 문서 목록이 정확히 필터링된다.
- 문서별 연결 WBS 요약이 표시된다.

3. 권한/노출 경계
- 프로젝트 읽기/편집 권한 범위를 벗어난 문서 연결이 차단된다.
- 태그 탭이 타 프로젝트 문서를 노출하지 않는다.

4. 회귀
- 기존 Documents 탭 문서 생성/조회 흐름이 유지된다.
- 기존 WBS 목록/편집/이동 동작이 깨지지 않는다.

## Exit Criteria

- 위 매트릭스 pass/fail 결과와 재현 절차가 `RIS-250` 코멘트에 기록됨.
- 실패 케이스는 재현 단계 + 기대/실제 결과 + 우선순위를 포함해 후속 이슈로 분리됨.
