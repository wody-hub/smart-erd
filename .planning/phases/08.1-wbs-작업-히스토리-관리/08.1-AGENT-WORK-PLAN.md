# 8.1단계 에이전트 작업 계획

## 목적

- GSD 관리 기준에서 8.1단계를 어떤 순서로 쪼개고 진행할지 고정한다.

## Stage 1

### 목표

- 작업-문서 연결과 태그 허브의 최소 동작을 만든다.

### 예상 child issue

1. `WBS 문서 연결 및 태그 MVP 백엔드`
2. `WBS 상세 문서 연결 UI 및 Tags 탭 MVP`
3. `WBS 문서 연결 및 Tags 탭 MVP QA`

### 선행 관계

1. 백엔드
2. 프런트
3. QA

## Stage 2

### 목표

- 작업 댓글과 활동 로그를 추가한다.

### 예상 child issue

1. `작업 공통 댓글/히스토리 모델`
2. `WBS 상세 댓글/히스토리 UI`
3. `댓글/히스토리 QA`

## Stage 3

### 목표

- 개인 TODO와 WBS 연결 정책을 제품에 반영한다.

### 예상 child issue

1. `개인 TODO 도메인 및 API`
2. `My Tasks 탭 및 WBS 연결 UI`
3. `개인 TODO 공개 경계 QA`

## Post-Review Remediation

### 목표

- 8.1 리뷰 과정에서 나온 구현/구조 후속 조치를 phase 가이드에 포함한다.

### 실제 child issue

1. `RIS-265` 개인 TODO를 팀 편집 권한과 분리
2. `RIS-266` My Tasks WBS 연결 실패 시 UI 상태 롤백
3. `RIS-267` TODO 서비스/화면 SRP 리팩터링

### 선행 관계

1. `RIS-265`
2. `RIS-266`
3. `RIS-267` (`RIS-265`, `RIS-266` 완료 후)
