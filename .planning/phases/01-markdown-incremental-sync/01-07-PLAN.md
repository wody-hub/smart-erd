**현재 코드 문제:**
```java
case SECTION_UPDATE_KEY -> {
    final var sectionId = payload != null ? payload.get("sectionId") : null;
    if (!(sectionId instanceof String sid) || sid.isBlank()) {
        yield List.of(rootScope());
    }
    yield List.of(new ScopeRef("section", sid, ScopeLockMode.EXCLUSIVE));
};
```
주의: 현재 코드에서 `sid.isBlank()` 검증은 이미 있으나, `yield List.of(rootScope())` 후 fallthrough로 다음 `yield`도 실행될 수 있는 구조적 버그가 있는지 확인 필요. Java의 `yield`는 block expression을 즉시 반환하므로 실제 fallthrough는 없지만, 가독성을 위해 명확하게 정리.

**수정 — `SECTION_UPDATE_KEY` 케이스 검증 강화:**

```java
case SECTION_UPDATE_KEY -> {
    if (payload == null) {
        yield List.of(rootScope());
    }
    final var sectionId = payload.get("sectionId");
    if (!(sectionId instanceof String sid) || sid.isBlank()) {
        yield List.of(rootScope());
    }
    // offset 검증: 음수 또는 역전된 offset은 document root scope로 fallback
    final var startOffset = payload.get("startOffset");
    final var endOffset = payload.get("endOffset");
    if (startOffset instanceof Number start && endOffset instanceof Number end) {
        if (start.longValue() < 0 || end.longValue() < 0 || start.longValue() > end.longValue()) {
            yield List.of(rootScope());
        }
    }
    yield List.of(new ScopeRef("section", sid, ScopeLockMode.EXCLUSIVE));
}
```

**Javadoc 업데이트:** resolve 메서드 Javadoc에 다음 추가:
- "sectionId가 null이거나 빈 문자열이면 document root scope로 fallback한다."
- "startOffset/endOffset이 음수이거나 역전(start > end)이면 document root scope로 fallback한다."

**주의사항:**
- `com.smarterd.support.AppStringUtils` 사용 여부 확인 — 프로젝트 컨벤션에 따라 `sid.isBlank()` 대신 `AppStringUtils.isBlank(sid)` 사용 가능하나, `instanceof String sid`로 이미 null-safe이므로 `sid.isBlank()` 직접 호출이 적절.
