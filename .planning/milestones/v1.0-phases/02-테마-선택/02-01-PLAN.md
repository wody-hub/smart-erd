다음 concrete state로 구현한다.

1. `client/src/constants/storage.ts`에 `THEME: 'smart-erd-theme'` 키를 추가한다.

2. `client/src/lib/theme.ts`를 새로 만든다. 아래 exact rule을 구현한다.
   - `ThemeName = 'paper' | 'graphite' | 'midnight'`
   - `DEFAULT_THEME = 'paper'`
   - `resolveStoredTheme(value)`:
     - `'paper'`, `'graphite'`, `'midnight'`면 그대로 반환
     - `null`, `undefined`, 빈 문자열, 그 외 문자열은 모두 `'paper'` 반환
   - `isDarkTheme(theme)`:
     - `paper => false`
     - `graphite => true`
     - `midnight => true`
   - `resolveMonacoTheme(theme)`:
     - `paper => 'vs'`
     - `graphite => 'vs-dark'`
     - `midnight => 'vs-dark'`
   - `applyThemeClass(target, theme)`:
     - `theme-paper`, `theme-graphite`, `theme-midnight` 3개 class 중 현재 theme만 남기고 나머지는 제거
     - `graphite`, `midnight`에서는 `.dark` class를 추가하고 `paper`에서는 제거한다
     - `.dark`는 token source selector가 아니라 Tailwind `dark:` variant 호환성을 위한 compatibility bit로만 취급한다

3. `client/src/stores/useThemeStore.ts`를 새로 만든다.
   - 상태: `theme`, `isDark`, `setTheme`
   - 초기값: `localStorage.getItem(STORAGE_KEYS.THEME)`를 `resolveStoredTheme()`로 정규화
   - `setTheme(nextTheme)` 호출 시:
     - localStorage에 `smart-erd-theme` 저장
     - `document.documentElement`에 `applyThemeClass(document.documentElement, nextTheme)` 적용
     - state `theme`, `isDark` 갱신

4. `client/src/main.tsx`에서 `createRoot()` 전에 bootstrap을 추가한다.
   - `document.documentElement`가 존재하면 localStorage 저장값을 읽어 `applyThemeClass(document.documentElement, initialTheme)` 실행
   - React mount 전에 class를 적용해서 refresh flash를 줄인다
   - bootstrap과 store hydration은 모두 `resolveStoredTheme()`를 사용해서 판정 기준이 drift하지 않게 한다

5. `client/src/hooks/useDarkMode.ts`는 더 이상 `MutationObserver + .dark`를 감시하지 않는다.
   - `useThemeStore((state) => state.isDark)`를 반환하는 compatibility adapter로 교체한다
   - 기존 Monaco consumer 4개 파일은 수정하지 않는다. hook 연결만 바뀌게 둔다

6. `client/test/unit/theme-config.test.ts`를 새로 만든다.
   - `resolveStoredTheme(null) === 'paper'`
   - `resolveStoredTheme('unknown') === 'paper'`
   - `isDarkTheme('paper') === false`
   - `isDarkTheme('graphite') === true`
   - `resolveMonacoTheme('midnight') === 'vs-dark'`
   - helper가 `theme-paper`, `theme-graphite`, `theme-midnight` class 이름을 사용한다
   - JSDOM target element에 `applyThemeClass()`를 적용했을 때:
     - `paper`는 `theme-paper`만 남고 `.dark`는 제거된다
     - `graphite`는 `theme-graphite`와 `.dark`가 함께 남는다
     - `midnight`는 `theme-midnight`와 `.dark`가 함께 남는다
